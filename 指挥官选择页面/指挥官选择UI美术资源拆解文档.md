# 指挥官选择 UI 美术资源拆解文档

## 1. 整体美术方向

目标风格：明亮卡通低模 3D、玩具模型质感、手绘木质 UI、柔和世界地图背景、清晰倒角、轻微颗粒笔触、暖色幻想策略游戏界面。

统一风格提示词：

```text
低多边形风格化 3D 游戏 UI 资源，明亮卡通配色，玩具模型质感，手绘木质纹理，柔和左上方光照，清晰倒角边缘，暖色幻想策略游戏界面，形状干净可读，轻微笔触颗粒，高质量手游 UI，透明背景
```

统一负面提示词：

```text
写实照片质感，暗黑恐怖风格，科幻金属界面，复杂花纹，过度磨损，脏乱背景，强透视，模糊边缘，真实人物照片，文字乱码，英文文字，中文文字，水印，图标混乱
```

建议统一画布：

- 基准 UI 分辨率：`1600 x 900`
- 单个 UI 零件格式：`PNG`
- 普通 UI 零件：透明背景
- 整屏背景：完整矩形背景
- 阴影：资源可自带轻微接触阴影，不要带过大的环境投影
- 光源方向：左上方柔和暖光
- 文字：全部不要让 AI 生成，后续在 Unity 中用 TextMeshPro 叠加

## 4. 不建议由 AI 生成的内容

以下内容建议在 Unity 内使用 TextMeshPro 或程序逻辑生成：

- 顶部标题：`选择指挥官`
- 返回按钮文字：`返回`
- 左侧分类文字：`指挥官`、`特性`、`初始兵种`
- 左侧状态文字：`未选择`、`未选择特性`、`未选择兵种`
- 底部指挥官名字：`伊莲娜`、`桂`、`阳`、`骑`、`冠`、`月`
- 卡牌占位大字：`像`
- 右下角按钮文字：`出征`

原因：AI 生成中文容易出现乱码、笔画错误、风格不统一；Unity 文本更容易改状态、改语言、做选中/禁用效果。

## 5. Unity 导入建议

- 木质按钮、木牌、卡牌外框建议导入为 `Sprite Mode: Single`
- 需要拉伸的木梁、信息条、按钮底板建议制作九宫格版本
- 每个透明 PNG 至少保留 `8-16 px` 安全留白，避免阴影和高光被裁切
- 同类元素保持统一光源方向：左上亮、右下暗
- 所有可点击按钮建议额外做三种状态：普通、按下、禁用
- 卡牌建议拆成：外框、头像/占位、名牌、选中高亮、文字，方便组合
