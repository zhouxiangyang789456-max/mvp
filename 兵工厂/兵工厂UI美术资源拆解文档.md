# 兵工厂 UI 美术资源拆解文档

## 1. 文档目标

本文用于拆解 `D:/prounity/mvp/兵工厂/兵工厂.png` 中的兵工厂生产界面 UI 元素，并为每个可独立生成的美术元素提供中文提示词。截图只作为视觉参考，不作为玩法或数值指令；具体玩法以 `计划/建筑与兵工厂系统设计文档.md` 为准。

目标是让外部 AI 先生成独立 PNG 资源，后续在 Unity 中由代码和 TextMeshPro 组合成可交互 UI。所有文字、数字、价格、单位名、属性值都不要让 AI 直接生成，统一在 Unity 中叠加。

## 2. 统一美术方向

目标风格：明亮卡通低模 3D、玩具模型质感、手绘木质与羊皮纸材质、柔和暖光、清晰倒角、轻微颗粒笔触、幻想策略游戏 UI。

统一正向提示词：

```text
低多边形风格化 3D 游戏 UI 资源，明亮卡通配色，玩具模型质感，手绘木质纹理，羊皮纸材质，柔和左上方暖光，清晰倒角边缘，轻微笔触颗粒，高质量手游策略游戏界面，形状干净可读，透明背景，不要文字
```

统一负面提示词：

```text
写实照片质感，暗黑恐怖风格，科幻金属界面，现代扁平 UI，复杂花纹，脏乱背景，强透视，模糊边缘，文字，数字，字母，中文，英文，水印，logo，真实人物照片，过度磨损，噪点过多
```

建议统一规格：

- 基准 UI 分辨率：`1600 x 900`
- 单个 UI 零件格式：`PNG`
- 普通 UI 零件：透明背景
- 大背景：完整矩形背景
- 光源方向：左上方柔和暖光
- 视角：正面 UI 视角，允许轻微 3D 厚度，不要强透视
- 文字：全部留空，不生成文字和数字

## 6. 生成与交付注意事项

- 所有 UI 底板不要生成文字，文字由 Unity TextMeshPro 实现。
- 单个元素尽量居中，四周留 8-16px 透明边距，避免裁切阴影。
- 木牌、按钮、面板要保持同一光源和同一棕色材质体系。
- 单位图标保持同一视角和比例，不要有明显不同画风。
- 如果 AI 无法稳定生成透明背景，先生成纯绿色或纯灰背景版本，再后期抠图。
- 生成整面板时不要把列表项、单位、按钮文字一起画死，优先保留可拆分性。
- 外部 AI 生成后建议统一导出为 PNG，并按第 3 节命名，放入 `D:/prounity/mvp/兵工厂/` 或 Unity 项目 `Assets/Art/UI/Armory/`。
