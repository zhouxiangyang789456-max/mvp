# 现有地形资源适配实施计划

## 1. 目标

把 `D:/prounity/mvp/地形/` 中的 8 张等距地形图实际接入战斗地图，替换当前白色方块染色占位资源，同时保持随机地图、寻路、部署、编队和战斗逻辑不变。

本阶段不制作建筑、道路和桥梁。

## 2. 资源检查结论

## 3. 实施步骤

1. 对每张 JPG 做背景提取：只移除棋盘格背景，保留地形主体、轮廓、阴影、构图和光照，输出真正透明 PNG。
2. 将结果保存到 `Assets/Resources/Battle/Terrain/Generated/`，使用稳定英文名称，运行时通过固定资源路径加载。
3. 配置 Unity Sprite 导入参数：单图、透明、Clamp、关闭 Mipmap、统一 Pixels Per Unit 和 Pivot。
4. 新增 `TerrainVisualCatalog`，集中保存 8 种 `TerrainType -> Sprite` 映射和显示参数。
5. `BattleGridController` 持有视觉配置，并在创建格子时传给 `BattleCellView`。
6. `BattleCellView` 使用等距 Sprite；资源缺失时仍回退到当前颜色方块，避免场景无法进入。
7. 保持逻辑格坐标仍为 `(x, 0, z)`，射线拾取、占用和寻路不读取 Sprite 尺寸。
8. 编译并检查所有地形均有映射，随机地图生成不受影响。

## 4. 显示策略

- 地形 Sprite 是预渲染等距图，采用面向战斗相机的竖直 Sprite 显示，不再把图片平放到 XZ 平面后二次透视。
- 每个 Sprite 的地面中心必须落在对应逻辑格中心。
- 平原、沙漠、水域使用相同基础显示尺寸。
- 森林、山地、雪山允许向上延伸，但逻辑占格仍只有一个。
- 排序继续按格子深度计算，并给单位、地形高物体预留排序层级。
- Sprite 资源为空或加载失败时使用 `SharedSprites.White + TerrainCatalog.GetColor()` 回退。

## 5. 验收标准

- 8 张输出均为真正带 Alpha 的 PNG，不再显示棋盘格背景。
- 8 种 `TerrainType` 在测试地图和随机地图中都能显示对应图片。
- 地块中心与逻辑格一致，点击和寻路位置不偏移。
- 森林、山地和雪山不会被后排普通地块错误覆盖。
- 单位仍生成在正确格子并显示在地形上方。
- 海洋和雪山仍不可通行，其余通行规则不变。
- 缺少任意图片时战斗仍可通过颜色占位资源启动。
- Runtime 与 Editor 程序集编译无错误。
