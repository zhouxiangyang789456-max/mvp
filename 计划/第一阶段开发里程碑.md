# 第一阶段开发里程碑

## 目标

把战斗页面第一阶段拆成可交付、可验收、可回退的小步，避免 UI、地图、单位、动画、阵型和性能优化同时推进导致风险叠加。

第一阶段最终交付目标：

- 指挥官选择页可进入战斗。
- 战斗页 UI 接近样例图。
- 地图为等距 tile 视觉。
- 单位为低模 3D。
- 单位按 RTS 方式点击地面缓慢移动。
- 点击敌方单位后追击并攻击。
- 阵型系统可在部署阶段和实时战斗阶段使用。
- 无明显卡顿。

## 里程碑 0：工程准备

### 内容

- 建立 Unity 目录结构。
- 导入参考图。
- 导入基础地形资源。
- 创建主场景：
  - `CommanderSelectScene`
  - `BattleScene`
- 建立基础脚本命名空间和目录。

### 验收

- Unity 可正常打开工程。
- 两个场景可打开。
- Console 无编译错误。
- 参考图和基础地形资源能在 Project 面板中找到。

## 里程碑 1：UI 还原骨架

### 内容

- 指挥官选择页搭出静态 UI。
- 战斗页搭出静态 UI。
- 使用 `ReferenceOverlay` 半透明叠底对齐。
- 建立基础 UI prefab：
  - `FramedPanel`
  - `GoldButton`
  - `CardSlot`
  - `CommanderPanel`
  - `MiniMapPanel`

### 验收

- 指挥官选择页布局接近 `指挥官选择页面/ui演示.png`。
- 战斗页布局接近 `战斗页面/ui展示.png`。
- 1600x900 下主要 UI 不重叠。
- 参考图叠底可开关。
- 截图保存到 `计划/UI截图记录/`。

## 里程碑 2：场景流程

### 内容

- 配置伊莲娜数据。
- 指挥官选择页点击伊莲娜卡牌。
- 左侧摘要和中央详情更新。
- 点击“出征”进入 `BattleScene`。
- `BattleScene` 读取 `BattleStartContext`。

### 验收

- 未选择指挥官时“出征”不可用。
- 选择伊莲娜后“出征”可用。
- 战斗页左下显示伊莲娜和 `86/100` 生命。
- 场景切换稳定，无报错。

## 里程碑 3：等距地图

### 内容

- 实现 `BattleGridController`。
- 实现 `GridToWorld` 和 `WorldToGrid`。
- 实现 `TestBattleMapData`。
- 使用基础地形拼出参考 `地图展示.png` 的测试地图。
- 暂不使用道路。

### 验收

- 地图尺寸为 `12x10`。
- 中央平原、左侧森林、前侧沙漠/水域、后侧山地/雪山分布清晰。
- 地图点击能转换为正确格子坐标。
- 海洋、雪山标记为不可走。

## 里程碑 4：性能基础设施

### 内容

- 实现 `BattleTickService`。
- 实现 `PathRequestQueue`。
- 实现 `PathfindingService`。
- 实现 `EffectPool`。
- 实现 `UiPool`。
- 预热部署高亮、选中圈、血条、开火特效。

### 验收

- 没有在 `Update()` 中执行无条件寻路。
- 对象池可取出和回收对象。
- 部署高亮进入/退出模式不产生大量 Instantiate/Destroy。
- Profiler 中没有明显 GC 峰值。

## 里程碑 5：单位占位与选择

### 内容

- 创建低模 3D 占位单位 prefab。
- 步兵先使用简化低模小队或临时胶囊体小队。
- 坦克先使用低模车体和炮塔。
- 生成己方 2 个步兵、1 个坦克。
- 生成敌方 1 个测试单位。
- 实现单选。

### 验收

- 己方和敌方颜色可区分。
- 玩家只能选中己方单位。
- 点击敌方单位不会选中敌方。
- 选中单位有光圈或描边。
- 单位血条显示在单位上方并朝向摄像机。

## 里程碑 6：RTS 移动

### 内容

- 点击地面生成移动命令。
- A* 计算路径。
- 单位沿路径点缓慢移动。
- 移动过程中朝向下一路径点。
- 新移动命令覆盖旧命令。
- 目标格被占用或不可走时显示无效反馈。

### 验收

- 点击单位后不显示移动范围。
- 点击可走地面后单位缓慢移动。
- 连续点击地面时单位执行最后一次命令。
- 点击海洋、雪山、被占用格不会移动。
- 连续下达移动命令无明显卡顿。

## 里程碑 7：攻击与追击

### 内容

- 点击敌方单位生成攻击命令。
- 单位追击敌方目标。
- 进入攻击距离后停止并攻击。
- 攻击按冷却扣血。
- 目标死亡后进入 `Dead`。
- 攻击特效使用对象池。

### 验收

- 己方单位能追击敌方单位。
- 进入射程后造成伤害。
- 攻击不是每帧扣血。
- 目标死亡后选中和命令状态正确清理。
- 攻击循环无持续 GC Alloc。

## 里程碑 8：阵型系统

### 内容

- 点击指挥官头像进入阵型部署模式。
- 显示 `5x5` 部署范围。
- 实现竖向、横向、方形阵型。
- 部署阶段阵型调整直接吸附到格子。
- 实时战斗阶段阵型调整生成移动命令。

### 验收

- 阵型按钮有高亮状态。
- 部署范围显示在地形上方、单位下方。
- 部署阶段单位可重新摆放。
- 实时阶段阵型移动不瞬移。
- 目标格不可用时有无效反馈。

## 里程碑 9：摄像机与小地图

### 内容

- 中键拖拽平移。
- WASD/方向键平移。
- 滚轮缩放。
- 摄像机边界限制。
- 小地图静态图。
- 点击小地图移动摄像机视野。

### 验收

- 摄像机不能无限移出地图。
- 滚轮缩放平滑。
- 小地图不使用实时 RenderTexture。
- 点击小地图能定位主视角。

## 里程碑 10：视觉和性能收尾

### 内容

- 对齐 UI 参考图。
- 补充按钮 hover/pressed/selected/disabled 状态。
- 检查 1600x900、1920x1080、1366x768。
- Profiler 检查 GC、Canvas rebuild、寻路、对象池。
- 保存最终截图。

### 验收

- UI 接近样例图。
- 三个 16:9 分辨率无明显重叠。
- 连续移动、攻击、阵型切换无明显卡顿。
- Console 无报错。
- Profiler 无每帧大量 GC Alloc。

## 推荐开发顺序

不要先做最终美术模型。先用占位低模和占位动画跑通规则，再替换正式模型。

推荐顺序：

```text
UI 静态骨架
  ↓
场景流程
  ↓
地图和坐标
  ↓
性能基础设施
  ↓
单位选择和移动
  ↓
攻击
  ↓
阵型
  ↓
摄像机和小地图
  ↓
正式低模单位和动画
  ↓
截图与性能验收
```

## 回退策略

如果某个模块拖慢进度：

- 低模单位动画没完成：先用无动画模型，保留移动和开火逻辑。
- 攻击特效没完成：先用命中闪烁和扣血。
- UI 切图不完整：先用统一 prefab 近似风格，不用 Unity 默认按钮。
- 阵型实时移动有问题：先保证部署阶段阵型，实时阶段暂时禁用阵型按钮。
- 小地图点击定位有问题：先保留静态小地图和放大按钮占位。

回退不能破坏核心链路：

```text
选择指挥官 -> 进入战斗 -> 选单位 -> 移动 -> 攻击 -> 阵型部署
```
