# MVP 第一阶段整合开发计划

## 目标

第一阶段要做出一个可运行、可验证、接近样例视觉的 Unity 战斗 MVP。

核心方向已经确定：

- 游戏参考：《指挥大师》式 RTS 即时指挥。
- 单位表现：低模 3D 单位，Unity 实时动画。
- 地图表现：等距 tile 视觉。
- 操作方式：点击单位选中，点击地面缓慢移动，点击敌方单位追击并攻击。
- 阵型系统：项目核心差异点，部署阶段和实时战斗阶段都可使用。
- UI 要求：参考样例图高还原，不使用 Unity 默认按钮风格。
- 性能要求：第一版就按防卡顿架构实现，不等后期返工。

## 第一阶段交付范围

### 必须完成

- 指挥官选择页 `CommanderSelectScene`。
- 战斗页 `BattleScene`。
- 伊莲娜指挥官选择和出征流程。
- 战斗主 UI：顶部栏、指挥官面板、卡牌栏、阵型按钮、小地图。
- 等距 tile 测试地图。
- 低模 3D 步兵和坦克。
- 己方初始单位：2 个步兵、1 个坦克。
- 敌方测试单位：至少 1 个，用于攻击验证。
- RTS 移动：点击地面后单位缓慢移动。
- 攻击命令：点击敌方单位后追击、进入射程、按冷却扣血。
- 部署阶段阵型：竖向、横向、方形，`5x5` 部署范围。
- 实时战斗阶段阵型：阵型按钮生成移动命令，不瞬移。
- 基础摄像机：中键拖拽、键盘平移、滚轮缩放、小地图定位。
- 性能基础设施：Tick 调度、寻路队列、对象池、UI 脏标记。

### 暂不完成

- 敌方 AI。
- 多单位框选和编队。
- 完整伤害结算、护甲、士气、弹药、反击。
- 城市占领结算。
- 卡牌真实效果。
- 多指挥官完整阵容。
- 道路铺设和道路自动连接。
- 小地图实时渲染。
- 复杂单位避让。

### 地图

第一版使用等距 tile 地图：

- 地图尺寸：`12x10`。
- 中央：平原。
- 左侧：森林。
- 前侧：沙漠、浅水、海洋。
- 后侧：丘陵、山地、雪山。
- 第一版不用道路。

移动逻辑：

- 底层用 `GridPosition` 做寻路、占用、部署范围、地形判断。
- Unity 中用 `WorldPosition` 平滑移动。
- 移动目标吸附到最近可走格中心。
- A* 寻路。
- 目标格被占用或不可走时拒绝移动。


单位阵营：

```text

```

玩家只能选中 `Player` 单位。点击 `Enemy` 单位时作为攻击目标。

### 低模 3D 资产

第一版使用低模 3D：

- 步兵：6 到 12 人小队，优先 6 人。
- 坦克：车体、炮塔、炮口分离。
- 动画最低要求：
  - `Idle`
  - `Move`
  - `Fire`
- 坦克额外要求：
  - 车体转向
  - 炮塔瞄准
  - 炮口后坐
  - 炮口火光

如果 Blender MCP 可用，可用于生成模型和动画；如果不可用，先手工或用占位低模资产。

## 战斗流程

```text
CommanderSelectScene
  ↓ 点击伊莲娜
  ↓ 点击出征
BattleStartContext 保存选择结果
  ↓
BattleScene
  ↓ 部署阶段
  ↓ 调整阵型
  ↓ 点击开始战斗
实时战斗阶段
  ↓ 选择单位
  ↓ 移动 / 攻击 / 阵型命令
```

## 操作规则

### 部署阶段

- 默认显示可部署区域。
- 可切换竖向、横向、方形阵型。
- 可调整己方初始单位站位。
- 调整站位直接吸附到部署格。
- 点击“开始战斗”进入实时战斗阶段。

### 实时战斗阶段

- 点击己方单位：选中单位。
- 点击地面：移动命令。
- 点击敌方单位：攻击命令。
- 右键或 Esc：取消选择或退出阵型部署模式。
- 普通移动不显示移动范围。
- 阵型命令会生成移动目标点，单位缓慢移动到阵型位置。

## 性能规则

第一版必须执行以下防卡顿规则：

- 禁止每帧寻路。
- 寻路使用 `PathRequestQueue`。
- 每帧最多处理 `1 - 2` 个寻路请求。
- 同一单位新寻路请求覆盖旧请求。
- 攻击追击重新寻路间隔不得低于 `0.3s`。
- 特效、血条、选中圈、部署高亮使用对象池。
- UI 使用脏标记刷新，不每帧全量刷新文本。
- 地图 tile 不加 Collider。
- 小地图第一版不使用实时 RenderTexture。
- 高频逻辑禁止 `Debug.Log`。
- `Update()` 中禁止 `GameObject.Find`、`FindObjectOfType`。

性能基础脚本：

```text
BattleTickService
PathRequestQueue
PathfindingService
EffectPool
UiPool
UnitHealthBarManager
```

## 验收标准

第一阶段完成时必须满足：

- 可以从指挥官选择页进入战斗页。
- 战斗页 UI 接近样例图。
- 地图使用基础地形拼出测试地图。
- 地图上有 2 个己方步兵、1 个己方坦克、至少 1 个敌方单位。
- 点击己方单位有选中反馈。
- 点击地面后单位缓慢移动。
- 点击敌方单位后单位追击并攻击。
- 攻击按冷却扣血，目标生命归零进入死亡状态。
- 部署阶段可切换阵型并调整站位。
- 实时战斗阶段阵型命令不瞬移。
- 摄像机可平移和缩放。
- 小地图为静态图，点击可定位视角。
- 连续移动、攻击、阵型切换无明显卡顿。
- Unity Console 无编译错误。
- Profiler 中无每帧大量 GC Alloc。

## 回退策略

如果开发中某模块拖慢进度：

- 低模动画没完成：先用无动画模型。
- 正式模型没完成：先用胶囊体/方块/简单低模占位。
- 攻击特效没完成：先用扣血和闪烁。
- UI 切图不完整：先用统一 prefab 近似风格，但不能用 Unity 默认按钮。
- 实时阵型有问题：先保证部署阶段阵型，实时阶段暂时禁用阵型按钮。
- 小地图定位有问题：先保留静态小地图和按钮占位。

不能回退的核心链路：

```text
选择指挥官 -> 进入战斗 -> 选单位 -> 移动 -> 攻击 -> 阵型部署
```
