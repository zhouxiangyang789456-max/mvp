# 嘲讽技能开发计划

## 1. 目标

新增战斗技能“嘲讽”。当前激活的玩家指挥官编队使用后，使一定范围内的敌方指挥官编队立即激活，并在持续时间内强制把施法编队作为攻击目标。

本技能必须遵守指挥官编队规则：技能由当前 `CommanderGroupRuntime` 发出，作用对象也是完整敌方编队；不得把玩家命令或强制目标直接发送给零散敌方士兵。

## 2. MVP 推荐参数

| 参数 | 推荐值 | 说明 |
| --- | ---: | --- |
| 技能 ID | `skill_taunt` | 稳定 ID，不使用显示名称作为逻辑键 |
| 技能类型 | 特殊技能、无指向即时释放 | 点击后立刻以施法编队锚点结算 |
| 有效范围 | 6 格 | 使用 Chebyshev 距离，与现有技能格子范围一致；边角也属于 6 格范围 |
| 持续时间 | 5 秒 | 足以让敌方响应并形成交战，同时不会长期剥夺 AI 决策 |
| 冷却时间 | 12 秒 | 从释放成功时开始计时；无有效目标时不进入冷却 |
| 作用数量 | 范围内全部敌方编队 | 每个敌方编队只记录一次，不按成员数量重复叠加 |
| 视野暴露 | 对受嘲讽敌方编队强制暴露施法编队 5 秒 | 不是向全地图所有敌人暴露 |

首轮开发将上述值放入 `SkillCatalog`，不在控制器内写死，便于试玩后调整。

## 3. “强制激活”的准确语义

嘲讽命中敌方编队后：

1. `Dormant`、`AcquireTarget`、调查或恢复中的敌方编队立即进入强制响应状态。
2. 清除其当前普通攻击、调查最后已知位置和恢复等待。
3. 以施法编队的 `GroupId` 作为强制目标，发出编队级 `AttackGroup`。
4. 持续时间内，普通 AI 选敌、距离更近的目标和原有仇恨均不能覆盖强制目标。
5. 敌方仍按完整阵型移动和攻击，不允许成员脱离编队无限追击。
6. 嘲讽结束后清除强制目标，敌方在下一次 AI 决策重新按正常视野选敌，不自动恢复嘲讽前已经失效的旧命令。

“激活”不等于让敌方玩家 UI 选择某支编队，也不修改 `ActiveCommanderGroupId`；它只改变敌方 AI 的临时战斗目标。

## 4. 范围与命中规则

- 距离以施法编队 `AnchorCell` 到敌方编队 `AnchorCell` 计算。
- 使用 `SkillRangeMath.Chebyshev`，范围条件为 `distance <= 6`。
- 只命中 `TeamId.Enemy`、未 `Defeated` 且已注册的编队。
- 不要求目标释放前已经可见；嘲讽本身可以惊动战争迷雾内、但实际位于范围内的敌人。
- 不穿越地图做无限检索；优先通过 `BattleSpatialIndex` 或编队注册表的低频范围查询获得候选编队。
- 同一敌方编队的多个成员进入范围，只算一个目标。
- 若范围内没有有效敌方编队，释放失败，提示“范围内没有可嘲讽的敌军”，不消耗冷却。

## 5. 视野与隐蔽规则

### 5.1 施法者暴露

- 释放成功时，施法编队主动暴露。
- 如果施法编队处于“隐蔽”，立即结束隐蔽状态；嘲讽与隐蔽不能同时维持。
- 每个受影响敌方编队获得对施法编队的临时强制视野，持续时间与嘲讽一致。
- 强制视野应绕过普通视野距离与隐蔽过滤，但只允许该敌方编队看到施法编队，不应顺带揭露施法者附近的其他友军。
- 施法者离开 6 格范围后，已命中的嘲讽和临时视野仍持续到 5 秒结束，避免每帧进出范围造成抖动。

### 5.2 目标信息

- 嘲讽不自动向玩家揭露战争迷雾中的敌方单位。玩家只知道“命中数量”；敌人仍按玩家方正常视野显示。
- 若后续希望做声波或问号提示，应只显示非精确方向提示，不能泄漏完整敌方位置。本项不属于 MVP。

## 6. 持续期间的优先级与打断

强制目标优先级高于普通敌军 AI 命令，但低于以下终止条件：

1. 施法编队 `Defeated`：所有相关嘲讽立即结束。
2. 受影响敌方编队 `Defeated`：移除该目标记录。
3. 战斗冻结、结算或离开战斗场景：清理全部记录。
4. 5 秒到期：结束嘲讽并移除临时视野。

其他规则：

- 玩家对施法编队下达移动、攻击或坚守命令，不会主动取消已经施加给敌人的嘲讽。
- 施法编队移动时，敌人继续追踪整个目标编队，但仍受现有路径、阵型和最大脱队距离约束。
- 嘲讽期间敌方寻路失败时进入短暂重试；不能改打其他目标。连续失败达到上限后原地等待，直到嘲讽结束。
- 再次嘲讽同一敌方编队时采用“覆盖来源并刷新到期时间”，不叠加多个强制目标。
- 若敌我双方未来都能使用嘲讽，采用“后施放覆盖先施放”；MVP 只开放给玩家方。

## 7. 数据设计

新增独立 `TauntEffectService`，不把临时效果散落到单位组件：

```csharp
TauntRuntimeState
{
    string AffectedGroupId;
    string SourceGroupId;
    float ExpiresAt;
    long SkillSequence;
}
```

建议接口：

```csharp
bool TryActivate(CommanderGroupRuntime source, float now, out int affectedCount, out string reason);
bool TryGetForcedTarget(CommanderGroupRuntime affected, float now, out CommanderGroupRuntime source);
bool IsSourceRevealedTo(CommanderGroupRuntime observer, CommanderGroupRuntime source, float now);
void Tick(float now);
void RemoveGroup(string groupId);
void Shutdown();
```

`EnemyGroupAiController` 每次普通选敌前先查询 `TryGetForcedTarget`。存在有效强制目标时，只允许维持或重新发出对该目标的 `AttackGroup`；不存在时才进入原有视野选敌流程。

`BattleVisionService` 增加有期限的定向强制可见层，不能只调用一次现有 `RevealNow`，因为下一次视野快照可能把目标重新移除。

## 8. 文件改造范围

- `Shared/Skills/SkillIds.cs`：增加 `Taunt`。
- `Shared/Skills/SkillCatalog.cs`：配置显示名、5 秒持续、12 秒冷却和 6 格范围。
- `Shared/Skills/SkillDefinition.cs`：优先增加明确的 `RangeCells`；不复用语义不符的 `RangeMultiplier`。
- `Battle/UI/BattleSkillBar.cs`：加入“嘲讽”按钮。
- `Battle/Skills/GroupSkillController.cs`：增加特殊技能释放入口。
- `Battle/Skills/TauntEffectService.cs`：新增范围结算、状态、到期和清理服务。
- `Battle/Vision/BattleVisionService.cs`：增加定向、限时强制视野。
- `Battle/AI/EnemyGroupAiController.cs`：在普通选敌前执行嘲讽强制目标优先级。
- `Battle/Commanders/CommanderGroupRegistry.cs`：编队注销时通知清理嘲讽状态，或提供等价生命周期事件。
- `Battle/UI/SkillTooltipView.cs`：显示“6 格内全部敌军强制攻击本编队，暴露 5 秒”。

不新增单兵玩家控制入口，不修改单位归属，不为 Codex 配置 Unity MCP。

## 9. UI 与反馈

- 技能按钮文字：“嘲讽”。
- 可用状态：战斗阶段、当前玩家编队有效、技能不在冷却。
- 成功反馈：“嘲讽生效：激活 N 支敌方编队，持续 5 秒”。
- 无目标反馈：“范围内没有可嘲讽的敌军”。
- 冷却提示显示剩余秒数。
- 施法编队头像或状态徽记显示 5 秒嘲讽标记；受影响敌方若当前可见，可显示愤怒/锁定标记。视觉图标可先用现有 UI 图形占位，不属于首轮逻辑验收门槛。

## 10. 自动化测试

至少增加以下 EditMode 测试：

1. 6 格内敌方编队命中，7 格外不命中。
2. 对角线 `(6, 6)` 按 Chebyshev 距离命中。
3. 一个敌方编队多个成员只计数一次。
4. 范围内无目标时释放失败且不进入冷却。
5. `Dormant` 敌军被命中后立即获得施法编队强制目标。
6. 嘲讽覆盖敌军原有普通目标。
7. 持续期间普通 AI 不能改选更近目标。
8. 5 秒到期后强制目标和定向视野同时清除。
9. 施法编队移动出范围后，已命中效果不会提前取消。
10. 施法者原本隐蔽时，成功释放会解除隐蔽。
11. 未被嘲讽的敌军不会因定向暴露而看到施法者。
12. 施法者或目标失败、战斗结算、服务关闭时状态完整清理。
13. 连续释放对同一目标刷新时间且不产生重复状态。
14. 嘲讽期间寻路失败不会让敌军改打其他编队。

## 11. 手工验收流程

1. 放置一支玩家编队、两支 6 格内敌军和一支 7 格外敌军。
2. 确认敌军初始未激活或正在攻击其他目标。
3. 点击“嘲讽”，检查两支范围内敌军立即转向施法编队，范围外敌军不受影响。
4. 在战争迷雾和隐蔽条件下重复，确认受影响敌军能持续锁定施法者，但玩家不会凭空看见隐藏敌人。
5. 移动施法编队，确认敌军继续以整编队方式追击，阵型与槽位锁定不被破坏。
6. 5 秒后确认敌军恢复普通 AI 选敌，临时视野消失。
7. 检查 Unity Console 无异常，项目编译无错误。

## 12. 开发顺序

1. 先增加纯数据状态与 `TauntEffectService`，完成范围、持续、覆盖和清理单元测试。
2. 接入 `BattleVisionService` 的定向限时视野并补视野隔离测试。
3. 接入 `EnemyGroupAiController` 强制目标优先级和寻路失败策略。
4. 接入技能目录、技能栏、提示文字与冷却。
5. 完整编译、运行 EditMode 测试，再进行战斗场景手工验收。

## 13. 首轮平衡观察项

试玩时重点记录：平均命中编队数、敌军实际接触施法者所需时间、5 秒内造成的集中伤害、嘲讽与坚守组合的生存能力。若过强，优先把范围从 6 降到 5 或冷却从 12 提到 15；不建议先缩短到 3 秒以下，否则远程或绕障敌军可能尚未形成有效响应技能就结束。
