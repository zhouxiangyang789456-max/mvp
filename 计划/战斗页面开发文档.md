# 战斗页面开发文档

## 项目目标

第一阶段实现一个可运行的 Unity 战斗页面，视觉上尽量贴近现有样例图，玩法上参考《指挥大师》式 RTS 即时指挥：选中单位后点击目标地点，单位沿路径缓慢移动；点击敌方目标或进入交战距离后执行攻击。普通移动不显示移动范围。本项目额外加入“阵型系统”，玩家可以在部署阶段通过竖向、横向、方形阵型调整部队站位。

本阶段不是做临时灰盒，而是做一个接近目标视觉的可交互版本。UI 边框、地图地形、指挥官面板、卡牌槽、小地图、单位信息都应尽量参考样例图来还原。

## 已确认技术路线

- 单位表现：第一版使用低模 3D 单位，Unity 实时播放动画。
- 地图表现：第一版使用等距 tile 视觉。
- 操作方式：普通战斗采用 RTS 即时移动，点击地面后单位缓慢移动，不显示移动范围。
- 阵型系统：仅在阵型部署模式显示 `5x5` 绿色部署范围。
- 道路系统：第一版不使用道路，第二阶段再处理道路素材尺寸修正和自动连接。

## 操作模式

战斗页需要明确区分“普通 RTS 指挥”和“阵型部署”，避免点击含义冲突。

### 战斗阶段

第一版战斗分为两个阶段：

```text
部署阶段
  ↓ 点击开始/出征后进入
实时战斗阶段
```

部署阶段：

- 默认显示可部署区域。
- 可以切换竖向、横向、方形阵型。
- 可以调整己方初始单位站位。
- 敌方单位不行动。
- 点击“开始战斗”按钮后进入实时战斗阶段。

实时战斗阶段：

- 默认进入普通 RTS 指挥模式。
- 单位可执行移动和攻击命令。
- 阵型按钮仍可使用，但只用于对已选单位下达阵型移动命令，不再免费调整站位。
- 敌方 AI 第一版不启用，敌方测试单位静止。

### 普通指挥模式

默认模式。

- 点击己方单位：选中单位。
- 框选己方单位：第一版可暂不做，第二阶段补。
- 点击地面：选中单位执行移动命令。
- 点击敌方单位：选中单位执行攻击命令。
- 右键或 Esc：取消选中或取消当前命令。
- 不显示移动范围。
- 点击空白 UI 区域不改变单位命令。
- 点击不可走区域时，显示无效反馈，不改变当前命令。

### 阵型部署模式

点击指挥官头像进入。

- 显示 `5x5` 部署范围。
- 普通移动命令暂停。
- 点击阵型按钮切换竖向、横向、方形。
- 点击己方单位后，再点击部署范围内格子，调整部署站位。
- 点击头像、右键或 Esc 退出阵型部署模式。
- 部署阶段内调整站位可以直接吸附到目标格。
- 实时战斗阶段内阵型调整必须生成移动命令，单位缓慢移动到阵型目标点，不能瞬移。

### 命令优先级

```text
阵型部署模式点击格子 > 阵型站位调整
普通模式点击地面 > 移动命令
普通模式点击敌方单位 > 攻击命令
普通模式点击己方单位 > 选择单位
```

### 选择规则

第一版只支持单选单位，第二阶段再做框选和编队。

- 当前选中单位显示选中光圈、描边或头顶标记。
- 选中己方新单位时，旧单位取消选中。
- 点击敌方单位不会选中敌方，只会作为攻击目标。
- 选中单位死亡时自动清空选择。
- 鼠标悬停单位时显示简易 Tooltip。

### 单位移动规则

玩法参考《指挥大师》式 RTS 即时指挥：

- 点击己方单位后选中单位。
- 普通移动不显示移动范围。
- 点击地面目标点后，单位沿路径缓慢移动到目标位置。
- 单位移动使用世界坐标路径，而不是一步一格瞬移。
- 地图仍然保留等距格子作为地形和站位基础，但操作体验是即时移动。
- 第一版移动路径可以先按格子中心点寻路，再用插值让单位平滑移动。
- 海洋和雪山默认不可走。
- 目标位置已有单位时，第一版直接拒绝移动并显示无效反馈。
- 移动过程中保留选中状态，允许后续点击新目标点改变移动命令。
- 新移动命令会覆盖旧移动命令和追击命令。
- 单位到达目标点后进入 `Idle`。
- 单位移动中可以被攻击。

### 单位攻击规则

第一版做最小可用攻击指令，不做完整数值平衡：

- 选中己方单位后点击敌方单位，进入攻击命令。
- 单位会向敌方目标移动。
- 进入攻击距离后停止移动并开始攻击。
- 如果敌方目标移动，攻击单位继续追击到攻击距离。
- 步兵和坦克第一版都使用简化攻击：
  - 步兵攻击距离短。
  - 坦克攻击距离更远，伤害更高。
- 如果单位移动过程中路过敌人，第一版可以先不自动开火；第二阶段再加自动交战和仇恨规则。
- 攻击反馈第一版使用血条减少、命中闪烁或简单弹道占位。
- 攻击按冷却间隔执行，不是每帧扣血。
- 目标死亡后攻击单位停止攻击并进入 `Idle`。
- 攻击单位被下达移动命令时，立即取消当前攻击命令。
- 目标超出攻击距离时，攻击单位进入 `Chasing`，追到射程内再攻击。
- 目标位于不可达位置时，单位移动到最近可达点并停止。

第一版数值：

```text
Infantry:
  MaxHealth: 100
  AttackRange: 2
  AttackPower: 8
  AttackCooldown: 1.0s

Tank:
  MaxHealth: 220
  AttackRange: 4
  AttackPower: 25
  AttackCooldown: 1.5s
```

伤害公式第一版直接使用：

```text
Damage = AttackPower
TargetHealth -= Damage
```

不计算护甲、地形、朝向、暴击、士气和弹药。

### 单位状态

```text
Idle       待命
Moving     移动到地面目标点
Chasing    追击攻击目标
Attacking  攻击中
Deploying  阵型移动中
Dead       死亡
```

状态切换规则：

- `Idle -> Moving`：点击地面。
- `Idle/Moving -> Chasing`：点击敌方单位。
- `Chasing -> Attacking`：进入攻击距离。
- `Attacking -> Chasing`：目标离开攻击距离。
- `Moving/Chasing/Attacking -> Deploying`：实时战斗阶段执行阵型移动命令。
- `Any -> Dead`：生命值小于等于 0。

### 阵营规则

第一版只做两个阵营：

```text
Player
Enemy
```

- 玩家只能选择 `Player` 单位。
- 玩家点击 `Enemy` 单位时作为攻击目标。
- 同阵营单位不能互相攻击。
- 敌方单位第一版不主动攻击。

### 测试敌方单位

为了验证攻击命令，第一版需要至少生成 1 个敌方坦克或步兵：

- 敌方单位不能被己方选择。
- 点击敌方单位时，己方选中单位执行攻击命令。
- 敌方单位显示不同阵营颜色和血条。
- 敌方单位第一版可以不主动移动、不主动攻击。

## 路径与碰撞

虽然地图有等距格子，操作体验仍然是 RTS 即时移动。第一版使用格子做寻路，再用世界坐标平滑移动。

性能约束：

- 禁止每帧重新寻路。
- 只在新移动命令、攻击目标位置变化超过阈值、路径失效时重新寻路。
- 攻击追击重新寻路间隔不得低于 `0.3s`。
- 地图格邻居缓存，寻路时避免频繁分配临时集合。

### 坐标规则

第一版使用“逻辑格子 + 世界坐标”的双层坐标：

- `GridPosition`：`Vector2Int`，用于寻路、占用、部署范围和地形判断。
- `WorldPosition`：`Vector3`，用于 Unity 中的真实单位位置。
- 每个格子有一个中心世界坐标。
- 单位移动目标点最终会吸附到最近可走格的中心点。
- 地形 tile 放在地面层，单位模型放在 tile 中心上方。
- 单位 Y 轴高度固定为地形表面上方的单位高度偏移。

等距坐标转换由 `BattleGridController` 统一提供：

```text
GridToWorld(Vector2Int grid) -> Vector3
WorldToGrid(Vector3 world) -> Vector2Int
IsWalkable(Vector2Int grid) -> bool
IsOccupied(Vector2Int grid) -> bool
```

### 第一版寻路

- 使用 A* 在格子上计算路径。
- 平原、森林、丘陵、沙漠、浅水默认可走。
- 海洋、雪山默认不可走。
- 单位沿路径点平滑移动。
- 每个路径点对应一个格子中心的世界坐标。
- 移动过程中单位朝向下一路径点。

### 碰撞处理

第一版简化：

- 单位占用一个逻辑格。
- 目标格被占用时拒绝移动，不自动寻找最近空格。
- 移动中不做复杂挤压。
- 多单位同时移动的避让放到第二阶段。

### 渲染层级

第一版使用 3D 单位和 2D/等距地形混合，需要固定层级：

```text
TerrainLayer     地形 tile
HighlightLayer   选中格、部署范围、路径目标
UnitLayer        低模 3D 单位
UnitUiLayer      单位血条、状态条、名称牌
BattleUiLayer    固定屏幕 UI
```

要求：

- 部署范围高亮显示在地形之上、单位之下。
- 单位选中光圈显示在单位脚下，高于地形。
- 单位血条始终面向摄像机。
- 战斗 UI 不参与世界排序，使用 Canvas。

### 摄像机控制

第一版应支持基础 RTS 摄像机：

- 鼠标中键拖拽平移。
- WASD 或方向键平移。
- 鼠标滚轮缩放。
- 小地图点击后移动主摄像机视野。
- 摄像机不能移出地图边界太远。

摄像机第一版固定斜俯视角，不允许旋转，只允许平移和缩放。

## 单位美术与动画制作方案

单位第一版确定使用 Blender 制作低模 3D 资产，再导出到 Unity。当前开发环境暂未暴露可直接调用的 Blender MCP 工具；如果后续接入 Blender MCP，可以让它自动生成基础模型、骨架/层级、关键帧动画并导出 `FBX` 或 `GLB`。如果暂时没有 Blender MCP，就先手工在 Blender 制作同样规格的资产。

### 技术路线

第一阶段使用“低模 3D 单位 + Unity 实时播放动画”：

- 地图是等距 2.5D 视觉，单位是低模 3D 模型。
- 摄像机固定斜俯视角，单位模型放在地形格上方。
- 模型材质使用简洁色块和少量描边/阴影，贴近样例里的小型军团标识。
- Unity 中通过 `Animator` 或脚本控制转向、移动、开火。

不采用 2D 序列帧作为第一版单位方案。原因：

- RTS 单位需要频繁转向、追击和开火。
- 坦克需要车体、炮塔、炮口分离控制。
- 2D 序列帧会带来多方向、多状态的大量图片资源。
- 低模 3D 更适合后续扩展阵营色、炮塔瞄准、转向和开火动画。

### 步兵资产规格

步兵第一版做成“小队单位”，不是单个士兵：

- 由 6 到 12 个低模士兵组成一个单位群。
- 士兵之间保持阵型间距。
- 单位根节点负责整体移动。
- 每个士兵可有轻微随机站位和动画偏移，避免过于机械。

动画：

- `Idle`：原地待命，轻微呼吸/武器晃动。
- `Turn`：单位朝目标方向旋转，士兵群整体转向。
- `Move`：步兵行军循环。
- `Fire`：举枪射击，带枪口闪光占位。
- `Hit`：受击闪烁或后仰。

第一版最低要求：

- `Idle`
- `Move`
- `Fire`

转弯第一版由 Unity 旋转单位根节点完成，后续再补专门 `Turn` 动画。

### 坦克资产规格

坦克第一版用单台低模坦克表示一个单位：

- 车体和炮塔分离。
- 车体负责移动方向。
- 炮塔可独立朝向攻击目标。
- 履带第一版用材质滚动或简单轮带动画占位。

动画：

- `Idle`：发动机轻微震动。
- `Turn`：车体转向目标方向。
- `Move`：沿路径缓慢移动，履带滚动。
- `TurretAim`：炮塔转向敌人。
- `Fire`：炮口后坐、炮口火光、炮弹/射线占位。
- `Hit`：受击闪烁或火花。

第一版最低要求：

- 车体转向。
- 缓慢移动。
- 炮塔朝向目标。
- 开火后坐和炮口闪光。

### Unity 动画控制

单位运行时拆成三层：

```text
UnitView
├── ModelRoot
├── BodyRoot
├── TurretRoot
├── MuzzlePoint
└── HealthBarAnchor
```

步兵没有 `TurretRoot` 时可以为空。

控制逻辑：

- `UnitMovementController` 控制路径和移动速度。
- `UnitFacingController` 控制转向。
- `UnitCombatController` 控制攻击距离、目标追击、开火间隔。
- `UnitAnimationController` 根据状态切换 `Idle`、`Move`、`Fire`、`Hit`。

状态机：

```text
Idle
  ↓ 点击地面
Turning
  ↓ 面向目标
Moving
  ↓ 到达目标
Idle

Idle/Moving
  ↓ 点击敌人
Chasing
  ↓ 进入射程
Attacking
  ↓ 目标死亡或取消命令
Idle
```

### Blender MCP 可做的工作

如果接入 Blender MCP，理论上可以自动化完成：

- 创建步兵低模小队。
- 创建坦克低模模型。
- 拆分坦克车体、炮塔、炮口节点。
- 制作关键帧动画：待机、移动、转向、开火、受击。
- 设置材质和简单贴图。
- 导出 `GLB` 或 `FBX`。
- 批量生成不同阵营配色版本。

需要注意：

- Blender MCP 可以辅助制作动画，但动画质量取决于提示、骨架/层级设计和迭代检查。
- 对步兵这种多人小队，第一版更适合做简化循环动画，不要一开始追求复杂骨骼。
- 坦克动画更适合自动化，车体、炮塔、炮口后坐都能用关键帧和节点旋转完成。

### 导出规范


- 选中描边或选中光圈。
- 血条挂点。

- `UnitView` 脚本。
- `Animator` 或脚本动画控制器。

## 阵型系统

阵型系统是本项目区别于“指挥大师”式移动的核心扩展。

### 入口

- 点击左下指挥官头像框。
- 地图上出现以指挥官为中心的部署范围。
- 默认范围为 `5x5`。
- 范围格子使用绿色高亮，参考 `队形系统` 图片。

### 阵型类型

```csharp
public enum FormationType
{
    Vertical,
    Horizontal,
    Square
}
```

### 阵型规则

竖向：

- 单位沿一列排列。
- 适合窄通道或纵深推进。

横向：

- 单位沿一行排列。
- 适合正面展开。

方形：

- 单位按紧凑矩形排列。
- 单位数量不足时从中心附近补位。

### 部署交互

```text
点击指挥官头像
  ↓
显示 5x5 部署范围
  ↓
点击阵型按钮
  ↓
刷新阵型预览
  ↓
点击某个单位
  ↓
单位高亮
  ↓
点击可部署格
  ↓
单位调整到部署格
```

### 第一版简化

- 部署阶段：阵型影响预览和初始站位，可以直接吸附到部署格。
- 实时战斗阶段：阵型影响移动目标点，单位必须缓慢移动到阵型位置。
- 不做阵型属性加成。
- 不做阵型碰撞自动挤压。
- 目标格不可用时不移动，并提示或闪红。

## 验收标准

### 指挥官选择页

- 页面整体布局接近 `指挥官选择页面/ui演示.png`。
- 能点击伊莲娜卡牌。
- 左侧摘要和中央详情能更新。
- 点击“出征”进入战斗场景。

### 战斗页视觉

- 页面布局接近 `战斗页面/ui展示.png`。
- 深蓝面板、金色边框、按钮风格尽量一致。
- 左下指挥官面板显示伊莲娜和生命 `86/100`。
- 底部有 6 个卡牌槽。
- 右下有小地图。
- 地图视觉参考 `地图展示.png`，第一版无道路。

### 即时移动与攻击玩法

- 地图上生成 2 个步兵和 1 个坦克。
- 地图上至少生成 1 个敌方测试单位。
- 步兵移动速度低于坦克。
- 坦克移动速度高于步兵。
- 点击单位后显示选中状态，不显示移动范围。
- 点击地面后单位缓慢移动到目标位置。
- 移动过程中可以重新点击地面改变目标。
- 点击敌方单位后，己方单位会靠近并进入攻击状态。
- 目标离开攻击距离时，己方单位会继续追击。
- 进入攻击距离后能造成简化伤害反馈。
- 攻击按冷却间隔扣血，目标生命归零后进入死亡状态。
- 不可走格和被占用格不能移动。
- 玩家不能选中敌方单位。

### 战斗阶段和命令

- 进入战斗页后先处于部署阶段。
- 部署阶段可以调整初始阵型。
- 进入实时战斗阶段后，点击地面执行普通移动命令。
- 实时战斗阶段中阵型命令会让单位缓慢移动到阵型目标点，不瞬移。
- 右键或 Esc 能取消当前选择或退出阵型部署模式。

### 摄像机

- 可以拖拽或键盘平移视角。
- 可以滚轮缩放。
- 点击小地图能移动主摄像机观察位置。
- 摄像机不会无限移出地图。

### 阵型系统

- 点击指挥官头像后显示绿色 `5x5` 部署范围。
- 可以切换竖向、横向、方形阵型。
- 当前阵型按钮有高亮状态。
- 单位能在部署范围内重新摆放。
- 阵型预览能随按钮切换更新。
- 部署阶段阵型调整可以吸附到格子。
- 实时战斗阶段阵型调整生成移动命令。

### 技术

- Unity Console 无编译错误。
- 场景切换稳定。
- UI 在 16:9 分辨率下不重叠、不溢出。
- 地图坐标、单位坐标、点击检测一致。
- 连续下达移动命令无明显卡顿。
- 进入/退出阵型部署模式不产生大量临时对象。
- 攻击循环无持续 GC Alloc。
- 主 UI 不每帧刷新全部文本。
- 小地图第一版不使用实时 RenderTexture。
- 寻路不在每帧执行，追击重新寻路有节流。
- 开火、命中、选中圈、部署高亮使用对象池。
- 高频逻辑中无 `GameObject.Find`、`FindObjectOfType` 和高频 `Debug.Log`。
