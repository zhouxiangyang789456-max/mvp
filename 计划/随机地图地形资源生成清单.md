# 随机地图地形资源生成清单

> 本文用于通过外部图像 AI 生成《指挥大师》随机地图的正式地形资源。项目现有 `Assets/Art/Battle/Terrain/Raw` 图片只作为风格参考，不作为生成工具的指令。

## 1. 现有资源评估

项目中已有以下地形参考图：平原、森林、丘陵、山地、沙漠、浅水、海洋，以及少量地形过渡图。

这些图片目前不建议直接用于正式游戏，原因如下：

- 多数 PNG 实际没有透明通道，棋盘格背景已经被烘进图片。
- 部分图片带黑色背景、文字残影或截图痕迹。
- 尺寸和构图不统一，宽高从约 211×214 到 738×595 不等。
- 地块菱形底座、透视角度、边缘厚度和中心位置不完全一致。
- 缺少独立的雪山地形图片。
- 每种地形只有一个主要版本，大面积随机地图会产生明显重复。
- 当前 `BattleCellView` 仍使用白色 Sprite 染色，没有加载这些图片。
- 现有图片是预渲染等距地块，不能直接平铺到当前水平 XZ 方块上，否则会产生二次透视变形。

结论：现有资源适合确定风格，不适合作为最终可交付资源。建议统一重新生成，并在 Unity 中把地形显示改为“等距 Sprite 地块”。

## 2. 首版资源范围

不制作建筑、道路和桥梁。首版只生成当前 `TerrainType` 使用的 8 种地形：

## 3. 所有资源必须遵守的生成规则

### 3.1 画布与文件

- 输出格式：真正带 Alpha 通道的 PNG，背景完全透明。
- 画布尺寸：`512 × 512 px`，所有资源完全一致。
- 色彩空间：sRGB。
- 一个文件只包含一个地块，不包含相邻地块、角色、建筑、道路、桥梁、UI 或文字。
- 禁止把棋盘格、白底、黑底、阴影背景或环境场景画进图片。
- 地块外允许柔和接触阴影，但阴影必须保留在透明画布内，不能形成整块背景。

### 3.2 构图与对齐

- 使用固定的 2.5D 等距战棋视角：水平旋转约 45°，俯视约 35°。
- 地块必须是正方形地面在等距视角下形成的菱形，不使用六边形。
- 菱形地面四角固定参考位置：左 `(32,352)`、上 `(256,240)`、右 `(480,352)`、下 `(256,464)`。
- 地块地面中心固定在 `(256,352)`。
- 树木和山峰可以向画布上方延伸，但不得改变底部菱形的尺寸和位置。
- 地块四边必须完整，不得被画布裁切。
- 所有资源使用同一镜头、同一缩放和同一地块厚度。

### 3.3 风格与光照

- 风格：精致、清晰、略带手绘感的 3D 渲染式 2.5D 策略游戏地块。
- 形体简洁，远距离仍能一眼识别地形类型。
- 光线固定从画面左上方照射，阴影落向右下方。
- 使用柔和环境光，不使用强烈电影级逆光、雾、景深和镜头光晕。
- 色彩明快但不过饱和，不能让地形抢过单位和指挥官 UI。
- 避免极细碎纹理；游戏缩小显示后仍需保持清楚。
- 不模仿具体游戏、艺术家或受版权保护作品，只使用通用的奇幻策略游戏美术描述。

### 3.4 地形辨识规则

- 平原是视觉基准，表面最平整、信息密度最低。
- 森林必须有明显树冠群，但中心附近保留少量可读地面。
- 丘陵只能是低缓土丘，轮廓不得接近山地。
- 山地使用裸岩主峰，但不能出现积雪。
- 雪山必须有明显积雪和寒冷色调，并且比普通山地更险峻。
- 沙漠以沙土和少量碎石为主，不出现海岸浪花。
- 浅水使用明亮青蓝色，能看见水下沙纹或浅底。
- 海洋使用更深的蓝色和更强波纹，与浅水形成明显层级。

## 5. 变体生成规则

每种地形的 `02`、`03` 版本使用同一提示词和同一参考图，只允许做以下变化：

- 平原：花草与碎石位置变化。
- 森林：树种比例、树冠大小和林间空隙变化。
- 丘陵：低丘位置和小石块变化，不改变高度等级。
- 山地：主峰朝向、副峰数量和山脚碎石变化。
- 雪山：积雪覆盖形状和副峰分布变化。
- 沙漠：风纹、小石块和耐旱草位置变化。
- 浅水：水下沙纹、焦散和小石块变化。
- 海洋：波纹形状和高光位置变化。

所有变体的菱形四角、地面中心、镜头、光照、色阶和地块厚度必须完全一致。建议先生成并确认 `01` 全套，再用这 8 张作为图生图参考制作 `02`、`03`，不要让 AI 分别自由发挥整套风格。

## 6. AI 输出后的人工验收

每张图导入项目之前必须检查：

- 文件确实包含 Alpha 通道；在纯红、纯绿、纯蓝背景上检查均无棋盘格或底色残留。
- 画布严格为 512×512。
- 菱形底座四角和中心与模板一致，叠加比较时不能漂移。
- 没有文字、水印、边缘残影、截图内容和被裁切物体。
- 左上光源和右下阴影一致。
- 缩小到 128×128 预览时仍能立即识别地形。
- 平原、丘陵、山地、雪山四个高度层级清楚。
- 浅水和海洋在不看名称时也能区分。
- 三个变体不会让玩家误认为是不同地形。

不合格图片不要在 Photoshop 中强行修补透视或缩放后混用，优先根据已通过的标准图重新生成。

## 7. Unity 导入建议

建议保存到：

```text
Assets/Art/Battle/Terrain/Generated/
```

Unity 导入设置建议：

```text
Texture Type: Sprite (2D and UI)
Sprite Mode: Single
Alpha Is Transparency: On
Mesh Type: Full Rect（首轮）
Filter Mode: Bilinear
Compression: Normal Quality 或 None（检查阶段）
Max Size: 512
Generate Mip Maps: Off
Wrap Mode: Clamp
Pivot: Custom，统一使用地面中心对应的固定 Pivot
```

实现时建议新增 `TerrainVisualCatalog` 配置资产，将每个 `TerrainType` 映射到 1-3 个 Sprite。变体选择必须由 `地图 seed + 格子坐标` 确定，不能使用运行时无种子的 `Random`，否则同一地图每次进入时外观会变化。

当前 `BattleCellView` 需要从“白色 Sprite 染色并平放”改为“读取等距 Sprite、使用统一 Pivot 和统一世界尺寸显示”。地形逻辑、随机地图数据和寻路规则不需要改变。
