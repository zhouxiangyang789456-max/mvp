# 战斗技能系统开发文档

## 1. 文档目标

在现有指挥官编队战斗基础上增加技能系统，技能分为：

- **常驻技能**：没有传统一次性释放流程，开启后进入持续战术状态，并由条件决定效果是否生效。
- **特殊技能**：兵种专属的主动技能，具有选取、持续时间或冷却时间。

首批技能：

| 分类 | 技能 | 适用对象 | 核心效果 |
| --- | --- | --- | --- |
| 常驻 | 防御／警戒 | 当前激活的指挥官编队 | 利用现有阵型功能排兵布阵，原地防御并自动攻击进入警戒范围的敌人 |
| 常驻 | 隐蔽 | 位于森林中的当前编队 | 以不能移动为代价进入隐蔽，对方失去对该编队的视野 |
| 特殊 | 远攻 | 远程单位 | 显示各远程单位攻击范围，在合法范围内选择格子或目标并发动远距离攻击 |
| 特殊 | 冲刺 | 坦克系单位 | 一定时间内大幅提高移动速度，结束后进入冷却 |

附件中的地图示意图、手形指针和红色范围光标仅作为交互与视觉参考，不作为数值或逻辑指令。

## 2. 必须遵守的控制原则

技能系统必须继续遵守现有指挥官编队规则：

1. 战斗中一次只激活一个 `CommanderGroupRuntime`。
2. 玩家点击技能按钮，是向当前激活编队发出技能命令，不能直接选中并控制一个士兵。
3. 兵种专属技能只由当前编队中符合条件的成员执行；不符合条件的成员保留阵型和当前合法状态。
4. 技能目标选择、寻路和攻击结果必须通过编队命令层分发到单位执行器。
5. 切换指挥官、右键取消、编队失败或技能被打断时，必须清理范围预览、光标和临时目标状态。

## 3. 技能分类与状态

### 3.1 常驻技能

常驻技能采用“战术模式”表达，同一编队同一时间最多启用一个常驻模式：

```text
None
Guard        // 防御／警戒
Concealment  // 隐蔽
```

- 再次点击当前常驻技能可关闭它。
- 开启另一个常驻技能时，先退出原模式，再进入新模式。
- 发出与模式冲突的命令时按规则自动退出，不保留隐藏的旧状态。

### 3.2 特殊技能

特殊技能采用主动释放流程：

```text
Ready -> Targeting / Activating -> Active -> Cooldown -> Ready
```

- `远攻` 需要进入 `Targeting` 目标选择状态。
- `冲刺` 不需要选取攻击目标，确认后直接进入 `Active`。
- 冷却按编队内每个符合条件的成员独立记录，UI 显示当前编队的可释放人数与最长剩余冷却。

## 4. 数据设计

### 4.1 技能静态定义

建议新增 `SkillDefinition` 与 `SkillCatalog`：

```csharp
string Id;
string DisplayName;
SkillCategory Category;       // Persistent / Special
SkillTargetMode TargetMode;   // None / Cell / EnemyGroup
UnitTag RequiredUnitTags;
TerrainType? RequiredTerrain;
float DurationSeconds;
float CooldownSeconds;
float RangeMultiplier;
float MoveSpeedMultiplier;
string IconAssetId;
string CursorAssetId;
```

首批稳定 ID：

```text
skill_guard
skill_concealment
skill_long_range
skill_sprint
```

### 4.2 编队技能运行时

建议在 `CommanderGroupRuntime` 持有 `GroupSkillRuntime`：

```csharp
PersistentSkillMode PersistentMode;
string TargetingSkillId;
long SkillSequence;
Dictionary<string, UnitSkillRuntime> UnitStates;
```

`SkillSequence` 与编队命令序号类似。异步目标选择、动画事件或延迟攻击执行前必须验证序号，防止旧技能结果覆盖新命令。

### 4.3 单位技能状态

```csharp
string SkillId;
SkillRuntimeState State;
float ActiveUntil;
float CooldownUntil;
bool IsEligible;
```

运行时状态不能写回 `UnitDefinition`；静态配置与本场战斗状态必须分离。

## 5. 技能一：防御／警戒

### 5.1 定位

防御／警戒是当前激活编队的常驻战术模式，复用现有阵型与重整功能，目标是“先布阵，再固守并攻击进入范围的敌人”。

### 5.2 启用条件

- 当前存在未失败的激活编队。
- 编队不处于部署、重整、占领或其他不可打断阶段。
- 编队存在至少一个可战斗成员。

### 5.3 操作流程

1. 点击“防御／警戒”。
2. 若当前阵型需要调整，打开现有阵型草稿，允许选择纵向、横向、方形或自定义 3×3 阵型。
3. 玩家确认后，整队执行 `Regroup` 并进入指定槽位。
4. 全员就位后进入 `Guard` 模式和 `Holding` 状态。
5. 敌人进入成员攻击范围后，按现有目标分配规则自动攻击，但成员不得主动追出阵型。

### 5.4 退出与打断

- 玩家发出移动、主动攻击、占领、重整或其他冲突命令时退出警戒。
- 编队被击退、阵型无法维持或失败时退出。
- 退出时保留当前阵型类型，但取消自动警戒目标。

### 5.5 首版数值建议

- 首版不额外增加防御数值，先完成“阵型 + 原地警戒 + 不追击”的行为闭环。
- 后续若需要数值强化，可增加小幅承伤降低，但必须进入配置，不写死在控制器中。

## 6. 技能二：隐蔽

### 6.1 定位

隐蔽是常驻战术模式。编队以完全停止移动为代价，在森林地形中对敌方隐藏。

当前项目没有独立“草丛”地形，首版将用户所说的草丛映射为 `TerrainType.Forest`。以后增加 Bush/Grass 地形时再扩展允许列表。

### 6.2 启用条件

- 当前编队所有存活且参与阵型的成员都已停止移动。
- 每个必要成员所在格均为 `Forest`。
- 编队不在攻击、重整、占领或冲刺状态。
- 编队没有刚刚造成伤害或受到伤害的暴露状态。

整队条件不满足时不允许部分成员单独隐蔽，以保证编队选择和视野反馈一致。

### 6.3 生效规则

- 启用后编队进入 `Concealment` 模式，并强制保持原地。
- `BattleVisionService` 在计算敌方可见目标时排除有效隐蔽编队。
- 己方仍正常看到自身编队、头像标记和血条。
- 敌方不能选中、锁定或自动攻击未被发现的隐蔽编队。
- 隐蔽编队发生被动警戒攻击或受击后的自动反击时，不解除隐蔽；这类攻击不能被当作玩家主动攻击命令。
- 敌方单位进入隐蔽单位一格以内时，触发近距离发现，敌方立即获得该隐蔽编队的视野。
- 已经在飞行中的投射物不取消；实际受到伤害后按暴露条件处理。
- 范围伤害可以命中隐蔽位置时，隐蔽不提供伤害免疫。

### 6.4 暴露条件

发生任意一项立即解除隐蔽：

- 玩家主动发出移动、主动攻击、远攻、占领、重整或冲刺命令。
- 任一成员离开森林格。
- 任一成员执行玩家主动下达的攻击；被动警戒攻击和自动反击不属于该条件。
- 任一敌方存活单位与隐蔽编队任一成员的距离进入一格以内。
- 任一成员受到伤害。仅收到攻击目标锁定但尚未受伤时，不因这一条暴露。
- 编队被特殊侦察机制发现（后续扩展）。
- 切换常驻模式或编队失败。

近距离发现按双方格子距离判定。首版统一使用现有战斗距离算法，将“进入一格以内”实现为距离 `<= 1`，包含相邻格；同格在正常占用规则下不会发生。发现检查必须先于敌方目标选择执行，使敌方在该逻辑帧获得视野后才能锁定和攻击。

被动攻击不刷新或解除隐蔽，也不触发 `RevealLockSeconds`。主动攻击、受伤、近距离发现或其他暴露条件成立后，建议增加短暂的 `RevealLockSeconds`，避免立刻反复进入隐蔽。只要敌方仍停留在一格以内，编队就不能重新进入隐蔽。

## 7. 技能三：远攻

### 7.1 适用对象

- 当前激活编队中带有远程兵种标签的存活成员。
- 建议新增明确的 `UnitTag.Ranged`，不要仅通过 `AttackRangeMax > 1` 猜测兵种身份。
- 混合编队中只有符合条件且技能已冷却的远程成员参加本次远攻，其余成员保持阵型。

### 7.2 选取流程

1. 点击底部技能栏中的“远攻”图标。
2. 系统进入 `Targeting`，取消普通地图点击路由，但不立即攻击。
3. 每个可用远程成员根据自己的当前位置、最小射程和最大射程显示攻击范围。
4. 鼠标位于所有远攻范围之外时，显示普通手形指针或不可用指针。
5. 鼠标进入至少一个单位的合法远攻范围后，切换为附件三所示的红色范围光标。
6. 点击合法格子或可见敌方目标后，系统计算哪些远程成员能覆盖该目标，并由这些成员共同执行远攻。
7. 右键、Esc、切换指挥官或再次点击技能按钮取消目标选择。

### 7.3 不同射程的显示

每个远程单位必须按自身 `AttackRangeMin / AttackRangeMax` 生成范围，不能统一采用编队最大射程。

推荐显示规则：

- 单个单位范围：半透明橙红格。
- 两个或更多单位范围重叠：提高亮度或描边强度。
- 当前鼠标格：使用红色四角范围光标并轻微脉冲。
- 小于最小射程的盲区：不高亮或显示暗红禁止状态。
- 障碍、不可攻击格或视野外目标：按规则显示为不可确认。

为了避免地图上同时出现大量杂乱色块，范围层不显示单位编号；鼠标悬停格旁的提示显示“可参与远攻：N 个单位”。

### 7.4 射程计算

- 首版沿用现有格子距离算法，与普通攻击范围保持一致。
- 远攻范围由基础射程乘 `RangeMultiplier` 得到，最后按配置的取整规则转换为格数。
- 必须同时验证最小射程、最大射程、目标可见性、目标存活状态和攻击者当前状态。
- 如果目标格没有合法敌人，是否允许对地范围攻击由单位 `AreaRadius > 0` 决定；普通单体远程单位只能选择合法敌人。

### 7.5 执行与打断

- 确认后创建编队级技能命令，再拆分为符合条件成员的攻击任务。
- 技能不要求其他成员离开阵型。
- 成员在技能确认后失去目标、死亡或被打断时，只取消该成员任务，不把命令转交给不合法成员。
- 首版建议远攻使用普通攻击伤害、扩大可选射程并进入独立冷却，避免同时引入新伤害体系。

## 8. 技能四：冲刺

### 8.1 适用对象

- 当前激活编队中带有 `UnitTag.Tank` 或明确坦克标签的存活成员。
- 不通过模型名称或显示名称判断坦克。
- 混合编队中仅坦克获得冲刺加速，但编队移动仍必须遵守阵型与速度上限规则。

### 8.2 编队速度规则

现有编队速度取成员最低移动速度。为避免坦克冲刺被步兵完全抵消，首版采用：

- 只有当当前编队的全部移动成员都是坦克时，允许启用冲刺。
- 启用后对全体坦克应用相同的移动速度倍率，继续保持阵型移动。

后续若需要混合编队冲刺，应先设计“临时分队”或“非坦克原地等待”，不能让坦克脱离编队形成隐性单兵控制。

### 8.3 生效流程

1. 点击“冲刺”。
2. 校验全坦克编队、技能冷却和当前状态。
3. 进入 `Active`，在持续时间内对移动速度应用倍率。
4. 玩家照常点击目标格，仍由编队命令层计算锚点、槽位和路径。
5. 持续时间结束后恢复基础速度并进入冷却。

### 8.4 打断

- 编队失败、进入隐蔽或发生禁止移动的状态时立即结束冲刺。
- 主动攻击是否结束冲刺由配置决定；首版建议攻击时结束，减少高速追击带来的状态复杂度。
- 被控制或无法寻路不会暂停持续时间。

## 9. UI 与鼠标交互

### 9.1 技能栏

在战斗界面底部建立当前激活编队的技能栏，参考附件一的位置：

- 只显示当前编队可用的技能。
- 常驻技能显示开启/关闭状态。
- 特殊技能显示冷却遮罩和剩余秒数。
- 因兵种条件不可用时置灰，并在悬停提示中说明原因。
- 切换指挥官时立即刷新技能列表、状态和冷却，不沿用上一编队的高亮。

### 9.2 图标资源

- 附件二的手形图标可以作为目标选择指针参考。
- 附件三的红色四角图标作为远攻合法范围光标参考。
- 两张参考图带有棋盘格背景，导入游戏前必须确认并清除假透明背景，输出真正透明 PNG。
- 建议最终尺寸至少为 64×64，统一中心点、留白、描边粗细和热点位置。
- Unity Cursor 的热点建议放在手指尖或范围图标中心，并同时提供硬件光标不支持时的 UI 跟随回退方案。

### 9.3 输入优先级

```text
UI 点击
  -> 技能按钮处理并消费事件
  -> 技能 Targeting 状态
  -> 阵型编辑状态
  -> 建筑交互
  -> 普通编队移动/攻击
```

技能选取期间不得把同一次左键点击继续传给普通移动或攻击逻辑。

建议新增：

```text
Assets/Scripts/Shared/Skills/
  SkillCategory.cs
  SkillDefinition.cs
  SkillCatalog.cs
  SkillIds.cs

Assets/Scripts/Battle/Skills/
  GroupSkillController.cs
  GroupSkillRuntime.cs
  SkillEligibilityService.cs
  SkillTargetingController.cs
  SkillRangePreview.cs
  ConcealmentService.cs
  SprintEffectService.cs

Assets/Scripts/Battle/UI/
  BattleSkillBar.cs
  BattleSkillButton.cs
  SkillTooltipView.cs
```

预计修改：

- `CommanderGroupRuntime.cs`：保存编队技能状态。
- `CommanderGroupCommandController.cs`：增加技能命令入口、打断和状态切换。
- `BattleVisionService.cs`：过滤有效隐蔽编队并主动刷新显隐。
- `UnitSelectionController.cs`：增加技能选取输入优先级，复用并扩展范围高亮。
- `UnitCombatController.cs`：接收远攻任务与技能序号。
- `UnitMovementController.cs`：读取冲刺速度倍率。
- `FormationController.cs`：为防御／警戒复用重整草稿和确认流程。
- `BattleUiController.cs`：创建并绑定技能栏。
- `UnitTag.cs`：增加明确的远程和坦克资格标签（若当前标签不存在）。
- `UiPoolType.cs / UiPool.cs`：增加技能范围与鼠标格高亮池。

## 11. 推荐开发阶段

### 阶段一：技能框架与 UI

- 建立技能定义、运行时状态、资格判断和技能栏。
- 完成指挥官切换、按钮置灰、取消和输入拦截。
- 暂不执行实际效果，只记录可靠的状态转换。

### 阶段二：防御／警戒

- 复用阵型编辑和重整。
- 实现 Holding、不主动追击和进入射程自动攻击。
- 验证新移动或攻击命令可以正确打断。

### 阶段三：远攻

- 扩展现有攻击范围池，支持当前编队多个远程成员的范围并集和重叠显示。
- 接入手形指针、合法范围光标、目标确认和取消流程。
- 实现不同兵种不同射程与参与成员计算。

### 阶段四：隐蔽与视野

- 在视野服务中加入隐蔽过滤和即时刷新。
- 实现全员森林、静止、攻击/受击暴露和重复进入限制。
- 验证敌方 AI、锁定和投射物边界行为。

### 阶段五：冲刺

- 增加坦克标签、全坦克编队校验、速度倍率、持续时间和冷却。
- 验证阵型速度、寻路、技能结束和攻击打断。

### 阶段六：数值配置与完整测试

- 将持续时间、倍率、冷却、射程倍率和暴露锁定时间全部配置化。
- 增加编辑器测试、运行时测试和多编队切换测试。
- 最后接入正式图标、音效、动画和特效。

## 13. 测试清单

### 13.1 通用

- 未激活编队时所有技能不可释放。
- 切换指挥官后只显示新编队技能状态。
- 右键、Esc、编队失败和场景退出能够清理预览与光标。
- 技能 UI 点击不会穿透成地图移动命令。
- 相同帧内冲突命令只有最新合法序号生效。

### 13.2 防御／警戒

- 编队完成重整后才进入警戒。
- 敌人进入射程后自动攻击，离开射程后不追击。
- 移动、主动攻击和重整可正确退出警戒。

### 13.3 隐蔽

- 全员静止且在森林时可以隐蔽。
- 任一必要成员不在森林时不能隐蔽。
- 隐蔽后敌方视野、选择和 AI 目标中都不存在该编队。
- 移动、主动攻击、受击和离开森林立即暴露；被动警戒攻击和自动反击保持隐蔽。
- 敌方单位进入一格以内时立即发现隐蔽编队，离开后仍需等待暴露锁定结束才能再次隐蔽。
- 已发射投射物与范围伤害按文档规则处理。

### 13.4 远攻

- 不同远程单位显示不同最小/最大射程。
- 重叠范围的亮度和参与人数正确。
- 鼠标进入合法范围时切换红色范围光标，离开后恢复。
- 只有能够覆盖目标且已冷却的远程成员参与攻击。
- 不合法目标不会消耗冷却。

### 13.5 冲刺

- 非全坦克编队不可启用首版冲刺，并显示原因。
- 冲刺期间编队保持阵型且速度倍率正确。
- 持续时间结束、攻击或失败时正确结束。
- 冷却结束前不能重复释放。

## 14. 验收标准

- 四个技能均从当前激活的指挥官编队入口释放，不存在玩家级单兵直接控制。
- 防御／警戒能够完成布阵、原地守卫和自动攻击闭环。
- 隐蔽只在整队静止且位于森林时生效，敌方视野与 AI 行为一致。
- 远攻能按每个远程单位实际射程显示范围，并在合法格切换范围光标。
- 冲刺只对符合资格的坦克编队生效，持续时间和冷却可靠。
- 所有技能的进入、取消、打断、结束和冷却状态都有明确 UI 反馈。
- 技能状态不破坏阵型、寻路、占领、战斗结算和多指挥官切换。
