## 术语表(效果 / 触发 / 作用域)

**效果**:攻=ModifyAttackPower;冷却=ModifyAttackCooldown;移速=ModifyMoveSpeed;减伤=ReduceIncomingDamage;生命=ModifyMaxHealth;暴击=ModifyCriticalChance;暴击伤=ModifyCriticalDamage;吸血=ModifyLifeSteal;护盾=GrantShield;灼烧=ApplyBurn;减速=SlowEnemy;斩杀=ExecuteBonus;反弹=ReflectDamage;射程=ModifyAttackRange;破甲=ReduceEnemyDefense;经济/金币获取=EconomyModifier;胜利金币=GoldOnWin;击杀金币=GoldOnKill;先手=FirstStrikeBonus;眩晕=StunEnemy;对减速增伤=ModifyDamageVsSlowed。

**触发**:常驻=Always;开战=OnBattleStart;命中=OnHit;受击=OnReceiveHit;击杀=OnEnemyDeath;低血=WhileGroupHealthBelowPercent;高血=WhileGroupHealthAbovePercent;敌低血=WhileEnemyLowHealth;敌减速时=WhileEnemySlowed;敌灼烧时=WhileEnemyBurning;阵型完整=WhileFormationIntact;每损生命=BasedOnHealthLost;每金币=BasedOnGold;首击=OnFirstAttack。

**作用域**(默认 `AllGroupMembers` 全队):全体敌=EnemyAll;最低血敌=EnemyLowestHealth;周围敌=NearbyEnemies;减速敌=EnemySlowed;灼烧敌=EnemyBurning。

**数值单位**:攻/减伤/移速/暴击/吸血等为百分比;灼烧"/5s"= 每秒伤害,持续 5 秒;减速"/3s"= 持续 3 秒。
