# 指挥官与卡牌重构方案(机制差异化)

> 本方案是对《指挥官设计文档》的**玩法层重构提案**。目标:让 6 位指挥官的流派**完全不重复**、每位指挥官能玩出**2 种明显差异的玩法**、卡牌摆脱"全是血量挂钩"的单调。
> 核心手段:引入 **6 个独占标签 + 12 条独占流派公式**,并从其他游戏英雄技能中借鉴机制(见各指挥官"灵感来源")。

---

## 1. 现状问题诊断

当前卡牌/流派体系有三个痛点:

1. **流派全部和血量挂钩**。现有 5 条流派公式:低血爆发 / 低血反扑 / 阵地防守 / 高血机动 / 厚血消耗——`low_health` / `high_health` / `max_health` 占绝对主导,标签池里 13 个标签有一半是生命相关。玩家构筑选择面窄,重复感强。
2. **指挥官流派互相重复**。按《指挥官设计文档》现状:薇拉/伊凡同挂高血机动流、奥莉薇/伊凡同挂低血爆发·阵地防守、达里奥/伊凡同挂厚血消耗流。选不同指挥官,商店出卡却高度相似。
3. **指挥官=只有一条主线**。主流派 + 副流派本质是同一标签家族的不同组合(低血爆发 vs 低血反扑),玩家感觉不到"换了个人在玩"。

本方案用"**独占机制主题**"一次性解决这三点:每位指挥官绑定一个**只有他能凑齐的独占标签**,围绕它建立 2 条独占流派。**共享(重复)由构造上不可能发生**——因为独占标签只出现在该指挥官的专属卡上。

## 2. 重构总览:6 大机制主题

| # | 指挥官 | 机制主题 | 独占标签 | 玩法关键词 | 借鉴灵感 |
|---|--------|---------|---------|-----------|---------|
| 1 | 伊莲娜 · 绯红猎犬 | **狂暴流** | `frenzy` | 低血爆发 / 吸血续航 | LoL 蛮王 Tryndamere(低血狂暴)、暗黑野蛮人(战斗狂怒)、Dota 血魔 |
| 2 | 卡西安 · 铁壁总督 | **铁壁流** | `bulwark` | 护盾吸收 / 荆棘反伤 | LoL 布隆 Braum(护盾)、魔兽防战、Dota 斧王(反击) |
| 3 | 薇拉 · 风隼 | **暗杀流** | `lethality` | 暴击爆伤 / 处决收割 | LoL 泰隆 Talon、Dota 幻影刺客(暴击)、守望先锋源氏 |
| 4 | 奥莉薇 · 鹰眼 | **焦土流** | `scorch` | 灼烧消耗 / 超远程压制 | 星际争霸攻城坦克、魔兽火法、英雄无敌大法师 |
| 5 | 达里奥 · 佣兵团长 | **雇佣流** | `mercenary` | 经济滚雪球 / 金币转战力 | TFT 福星/海盗、炉石节奏贼、暗黑金币 |
| 6 | 伊凡 · 夜鸦 | **冰霜流** | `frost` | 开场控场 / 阵地控场 | LoL 艾希 Ashe(减速)、Dota 水晶室女、魔兽冰法 |

**关键机制 —— 独占标签**:`frenzy / bulwark / lethality / scorch / mercenary / frost` 只出现在该指挥官本人的 3 张专属卡上,其他任何卡(含通用新卡)都不携带。卡池其他标签可共享,但**流派的"字根"(独占标签)不可共享** → 流派重复在构造上不可能发生。

## 3. 卡牌系统扩展

### 3.1 新效果类型(扩 `TraitEffectKind`)

| 新效果 | 说明 | 数值语义(与现有 Value 约定一致) | 优先级 |
|--------|------|--------------------------------|--------|
| `ModifyAttackRange` | 攻击范围 | +0.30 = 射程 +30% | P1(奥莉薇核心) |
| `ModifyCriticalChance` | 暴击率 | +0.20 = 20% 概率 2 倍伤 | P1(薇拉核心) |
| `ModifyCriticalDamage` | 暴击伤害 | +0.50 = 暴击 2.5 倍 | P2 |
| `ModifyLifeSteal` | 吸血 | +0.15 = 造成伤害的 15% 回血 | P1(伊莲娜) |
| `GrantShield` | 护盾 | +0.20 = 获得最大生命 20% 的护盾 | P1(卡西安) |
| `ApplyBurn` | 灼烧 | +0.05 = 每秒受攻 5% 伤害,持续秒见 Duration | P2(奥莉薇) |
| `SlowEnemy` | 减速敌人 | -0.30 = 移速 -30% | P1(伊凡) |
| `ModifyDamageVsSlowed` | 对减速敌增伤 | +0.15 | P2 |
| `ExecuteBonus` | 斩杀增伤 | 对低血敌人 +0.50 | P1(薇拉) |
| `ReflectDamage` | 反弹伤害 | +0.10 = 反弹所受伤害 10% | P2(卡西安) |
| `EconomyModifier` | 经济加成 | 商店金币结算乘区 | P1(达里奥) |
| `GoldOnWin` / `GoldOnKill` | 金币获取 | 胜利/击杀额外金币 | P1(达里奥) |
| `FirstStrikeBonus` | 先手加成 | 开场 N 秒攻 +0.20 | P1 |
| `ReduceEnemyDefense` | 破甲 | 敌人防御 -0.08 | P2 |

> 沿用现有"正负值语义":add 类效果(攻/移/射程/暴击)正值增强,reduction 类(冷却/减伤)正值降低;新效果中 `SlowEnemy` 用正值表示减速幅度,与 `TriggerValue` 区分(见 3.3)。

### 3.2 新触发条件(扩 `TraitTriggerKind`)

| 新触发 | 说明 | 落地依赖 |
|--------|------|---------|
| `OnEnemyDeath` | 敌人死亡时 | 击杀结算 |
| `OnHit` | 攻击命中时 | 命中结算 |
| `OnReceiveHit` | 受到攻击时 | 受伤结算 |
| `WhileEnemyBurning` | 敌人处于灼烧时 | 灼烧状态 |
| `WhileEnemySlowed` | 敌人处于减速时 | 减速状态 |
| `WhileEnemyLowHealth` | 敌人生命低于阈值时 | 敌方血量读取 |
| `BasedOnHealthLost` | 按损失生命插值(每损失 1% 生效) | 线性插值结算 |

### 3.3 新作用域(扩 `TraitTargetScope`)

| 新作用域 | 说明 |
|---------|------|
| `EnemyAll` | 所有敌人 |
| `EnemyFrontline` | 敌方前排 |
| `EnemyLowestHealth` | 敌方最低生命单体(处决目标) |
| `EnemyBurning` / `EnemySlowed` | 灼烧中 / 减速中的敌人 |
| `NearbyEnemies` | 编队周围敌人(阵地控场) |

> 现有 `FrontlineMembers` / `RangedMembers` 已定义未放行;新作用域统一放行后,与敌方目标选取共用一条结算。

### 3.4 新标签体系

**独占标签(只出现在对应指挥官专属卡,不可共享):**

```
frenzy(伊莲娜)  bulwark(卡西安)  lethality(薇拉)
scorch(奥莉薇)  mercenary(达里奥)  frost(伊凡)
```

**通用新标签(出现在通用卡,可服务任意指挥官):**

```
critical  shield  burn  slow  control  lifesteal
economy  range  execute  first_strike  reflect  armor_pen
```

**效果——独占标签使流派"构造上不可重复"**:`TraitBuildAnalyzer` 的流派公式以独占标签为旗舰(权重 ×2)。独占标签只有该指挥官的专属卡携带,所以该流派只有选该指挥官且装备其专属卡才可能得分。通用标签仍参与其他流派,但**指挥官身份由独占标签锚定**。

## 4. 六位指挥官重构详设

每位指挥官结构:

- **签名被动**(阶段一可落地,沿用现有白名单效果/触发/作用域)
- **3 张专属卡**:路线 A 核心卡 / 路线 B 核心卡 / 双路线共用卡,全部携带独占标签
- **2 条独占流派**(`ArchetypeRegistry` 新增),旗舰均为独占标签 ×2
- **2 种玩法路线**:商店 §5.1 动态判定玩家实际投入哪条 → 主流派随之切换

### 4.1 伊莲娜 · 狂暴流(`frenzy`)

- **签名被动 · 背水一战**(可落地):`WhileGroupHealthBelowPercent(0.35)` + `ModifyAttackPower(+0.25)`,`AllGroupMembers`。
- **灵感**:LoL 蛮王——血量越低越疯;暗黑野蛮人——战斗狂怒。

| 专属卡 | 稀有度 | 效果(效果/触发/作用域/数值) | 标签 | 路线 |
|--------|--------|------------------------------|------|------|
| 嗜血狂暴 | Epic | `WhileGroupHealthBelowPercent(0.50)` + `ModifyAttackPower(+0.25)` | frenzy, attack, low_health | A 核心 |
| 死战不退 | Rare | `WhileGroupHealthBelowPercent(0.35)` + `ModifyLifeSteal(+0.15)` | frenzy, lifesteal, low_health | B 核心 |
| 血之代价 | Rare | `BasedOnHealthLost` + `ModifyAttackPower`(每损失 1% 生命 +0.5%) | frenzy, attack, max_health | 共用 |

- **独占流派**(`ArchetypeRegistry` 新增):
  - `archetype_frenzy_burst` 狂暴爆发流 = `frenzy×2, attack×1, low_health×1`
  - `archetype_frenzy_sustain` 嗜血续航流 = `frenzy×2, lifesteal×1, defense×1`
- **两种玩法**:
  - **路线 A · 玻璃大炮**:装备「嗜血狂暴」+ 通用暴击/攻击卡,压血线换极限输出,快节奏秒杀。
  - **路线 B · 嗜血不死**:装备「死战不退」+ 通用吸血/防御卡,低血安全区打持久,残局收割。
- **上手难度**:★★★★☆ —— 压血线防被秒(与现设计一致)。

### 4.2 卡西安 · 铁壁流(`bulwark`)

- **签名被动 · 铁壁防线**(可落地):`WhileGroupHealthAbovePercent(0.70)` + `ReduceIncomingDamage(0.20)`,`AllGroupMembers`。
- **灵感**:LoL 布隆——举盾吃伤害;Dota 斧王——反击螺旋。

| 专属卡 | 稀有度 | 效果 | 标签 | 路线 |
|--------|--------|------|------|------|
| 钢铁壁垒 | Epic | `OnBattleStart` + `GrantShield(+0.20)`,`AllGroupMembers`(开场全队护盾) | bulwark, shield, formation | A 核心 |
| 荆棘反震 | Rare | `OnReceiveHit` + `ReflectDamage(+0.10)` | bulwark, reflect, defense | B 核心 |
| 坚守阵线 | Rare | `WhileFormationIntact` + `ReduceIncomingDamage(+0.10)` | bulwark, defense, formation | 共用 |

- **独占流派**:
  - `archetype_bulwark_shield` 护盾堡垒流 = `bulwark×2, shield×1, formation×1`
  - `archetype_bulwark_thorns` 荆棘反伤流 = `bulwark×2, reflect×1, defense×1`
- **两种玩法**:
  - **路线 A · 护盾堡垒**:开场护盾吸收伤害,维持高血,正面对推。
  - **路线 B · 荆棘反伤**:堆减伤 + 反弹,让敌人打不死你反而自己被弹死。
- **上手难度**:★★☆☆☆(A)/★★★☆☆(B)。

### 4.3 薇拉 · 暗杀流(`lethality`)

- **签名被动 · 猎风疾行**(可落地):`Always` + `ModifyMoveSpeed(+0.15)`,`AllGroupMembers`。
- **灵感**:LoL 泰隆——贴脸爆发;Dota 幻影刺客——恩赐解脱暴击。

| 专属卡 | 稀有度 | 效果 | 标签 | 路线 |
|--------|--------|------|------|------|
| 致命一击 | Epic | `Always` + `ModifyCriticalChance(+0.20)` | lethality, critical, attack | A 核心 |
| 斩首行动 | Rare | `WhileEnemyLowHealth(0.30)` + `ExecuteBonus(+0.50)` | lethality, execute, attack | B 核心 |
| 影袭 | Rare | `OnBattleStart` + `FirstStrikeBonus(+0.20)`,`AllGroupMembers`(开局 3 秒) | lethality, first_strike, mobility | 共用 |

- **独占流派**:
  - `archetype_lethality_crit` 暴击刺客流 = `lethality×2, critical×1, attack×1`
  - `archetype_lethality_execute` 处决收割流 = `lethality×2, execute×1, attack×1`
- **两种玩法**:
  - **路线 A · 暴击刺客**:堆暴击率/暴击伤,一刀带走满血脆皮。
  - **路线 B · 处决收割**:堆斩杀线,专打残血,配合高机动收割全场。
- **上手难度**:★★★☆☆。

### 4.4 奥莉薇 · 焦土流(`scorch`)

- **签名被动 · 强袭火力**(可落地):`Always` + `ModifyAttackPower(+0.12)`,`AllGroupMembers`。
- **灵感**:星际攻城坦克——远程范围压制;魔兽火法——持续灼烧。

| 专属卡 | 稀有度 | 效果 | 标签 | 路线 |
|--------|--------|------|------|------|
| 焦土地狱 | Epic | `OnHit` + `ApplyBurn(+0.05, 5s)`,`EnemyAll`(命中附加灼烧) | scorch, burn, attack | A 核心 |
| 超视距打击 | Rare | `Always` + `ModifyAttackRange(+0.30)` | scorch, range, attack | B 核心 |
| 火力压制 | Rare | `OnHit` + `SlowEnemy(+0.10)`,`EnemyAll` | scorch, slow, attack | 共用 |

- **独占流派**:
  - `archetype_scorch_burn` 焦土灼烧流 = `scorch×2, burn×1, attack×1`
  - `archetype_scorch_range` 超远程压制流 = `scorch×2, range×1, attack×1`
- **两种玩法**:
  - **路线 A · 灼烧消耗**:命中挂灼烧,持续掉血,打消耗战。
  - **路线 B · 超远程放风筝**:堆射程,让对方摸不到你。"远程火力 = 攻击范围增加"在此落地。
- **上手难度**:★★★☆☆。注意:超视距打击的射程结算(`ModifyAttackRange`)是本方案第一个新结算,需 `RangedMembers` 作用域放行。

### 4.5 达里奥 · 雇佣流(`mercenary`)

- **签名被动 · 速成训练**(可落地):`WhileGroupHealthAbovePercent(0.70)` + `ModifyAttackPower(+0.12)`,`AllGroupMembers`。
- **灵感**:TFT 福星/海盗——经济滚雪球;炉石节奏贼——用费用滚雪球;暗黑——金币转化。

| 专属卡 | 稀有度 | 效果 | 标签 | 路线 |
|--------|--------|------|------|------|
| 雇佣兵团 | Epic | `OnBattleStart` + `GoldOnWin`,(胜利额外金币) | mercenary, economy, commander | A 核心 |
| 战利品掠夺 | Rare | `OnEnemyDeath` + `GoldOnKill` | mercenary, economy, attack | B 核心 |
| 佣金合同 | Rare | `BasedOnGold` + `ModifyAttackPower`(每 10 金币 +1%) | mercenary, economy, commander | 共用 |

- **独占流派**:
  - `archetype_mercenary_snowball` 滚雪球经济流 = `mercenary×2, economy×1, commander×1`
  - `archetype_mercenary_goldpower` 金币转战力流 = `mercenary×2, economy×1, attack×1`
- **两种玩法**:
  - **路线 A · 滚雪球**:胜利/击杀赚金币,商店多刷,卡池碾压。
  - **路线 B · 金币转战力**:用金币直接换全队攻击,后期一波流。
- **上手难度**:★★★★★ —— 前期脆、单位弱,精打细算金币(与现设计一致)。`BasedOnGold` 需要一个"按当前金币量缩放"的新结算。

### 4.6 伊凡 · 冰霜流(`frost`)

- **签名被动 · 追歼令**(可落地):`WhileGroupHealthAbovePercent(0.70)` + `ModifyMoveSpeed(+0.20)`,`AllGroupMembers`。
- **灵感**:LoL 艾希——寒冰减速风筝;Dota 水晶室女——范围冰冻控制。

| 专属卡 | 稀有度 | 效果 | 标签 | 路线 |
|--------|--------|------|------|------|
| 冰霜新星 | Epic | `OnBattleStart` + `SlowEnemy(-0.30, 3s)`,`EnemyAll`(开场全体减速) | frost, slow, control | A 核心 |
| 极寒之域 | Rare | `Always` + `SlowEnemy(-0.20)`,`NearbyEnemies`(阵地周围减速) | frost, slow, idle | B 核心 |
| 霜之契约 | Rare | `WhileEnemySlowed` + `ModifyDamageVsSlowed(+0.15)`,`AllGroupMembers` | frost, control, attack | 共用 |

- **独占流派**:
  - `archetype_frost_burstcontrol` 开场控场流 = `frost×2, slow×1, control×1`
  - `archetype_frost_zone` 阵地控场流 = `frost×2, idle×1, defense×1`
- **两种玩法**:
  - **路线 A · 开场爆发控场**:开局全屏减速,配合高血移速先手集火。
  - **路线 B · 阵地控场**:站桩防守,敌人靠近即减速,配合霜之契约增伤。
- **上手难度**:★★★★☆。

> **与旧文档的关系**:旧的 8 条共享流派(低血爆发/阵地防守/高血机动/厚血消耗/……)**保留但不作任何指挥官身份锚点**。它们是通用卡池的"泛流派",任意指挥官可借通用卡漂入;指挥官身份一律由独占流派定义。这样:同一指挥官 2 条独占路线 = 2 种玩法;不同指挥官独占标签不同 = 永不重复。

**独占流派成型速度**:独占标签只出现在该指挥官 **20 张专属卡**上,且 `StackPolicy = UniquePerCommander`。装备 2 张专属卡 → 独占标签计数 = 2 → 旗舰权重 ×2 → 得 4 = 进入"正在成型";装备 3 张 → 计数 3 → 得 6 = 已成型。**收集专属卡 = 流派成型**,与"指挥官=流派入口"天然咬合。

## 8. 商店集成

### 8.1 专属卡进池规则(新增)

- `CommanderDefinition` 增加 `ExclusiveTraitIds`(该指挥官 20 张专属卡 Id)。
- `SettlementShopSession.RollOffers()` 构建卡池时过滤:`TraitCatalog` 增加 `ExclusiveOwner(id)` 查询;专属卡**仅当**其所属指挥官在 `ActiveCommanderIds` 中时进池。
- 选人即决定专属卡池 → 每局实际池子 = 150 − 100(5 位未选中指挥官的专属卡)= **50**,选不同指挥官商店彻底不同,玩家感受差异最大化。

### 8.2 §5.1 流派补强(现有逻辑复用,零改动)

- 玩家装备专属卡 → 独占标签进入 `OwnedTraitTags` → `Analyze` 判出该指挥官的独占流派为主流派(得分高) → `ArchetypeSynergyMultiplier` 自动偏向该流派公式的**其他标签**(attack / critical / lifesteal / …)。
- 玩家买哪条路线的通用卡 → 该路线的通用标签计数高 → 主流派在那两条独占流派之间由玩家实际投入**动态切换**。这正是"同一指挥官 2 种玩法"在商店侧的落地:不锁死,由投入决定。

### 8.3 指挥官方向补强(方案 B,来自旧文档)

- `TraitShopDirector` 增加 `CommanderAffinityMultiplier`:候选卡携带所选指挥官任一独占流派公式标签时 ×1.25;选择"本局主方向"时该方向 ×1.5、副方向 ×1.25。
- 达里奥的"双面合同"(主+副同时补强)天然适配:他的两条独占流派都靠 `mercenary` + 不同通用标签,商店会同时引导两条线。

### 8.4 决定性保持

`Roll(seed, context, pool, count)` 现有签名不变;过滤只发生在调用方构建 `pool` 时。同种子同上下文仍产出同结果,确定性测试不受影响。

## 10. 平衡框架与风险

- **独占标签的强度闸门**:独占流派成型 = 收集专属卡(每张 1 独占标签)。装备 2 张即 Forming,但**装备槽仅 4 个** → 玩家最多装 4 张专属卡,独占标签计数封顶 4;路线 B 的通用侧需让出 1+ 槽给通用卡,天然限制超模。卡池大(每指挥官 20 专属)只扩选择面,不破上限。
- **数值校准**:新效果首次落地按现有量级(0.10–0.25)起步;`ApplyBurn`(每秒 5%)、`ExecuteBonus`(+50%)、`BasedOnGold` 等属于高收益机制,需在 `TraitEffectService` 做上限保护(叠加上限 / 次数上限)。
- **敌方目标选取的新结算**:`EnemyAll` / `NearbyEnemies` / `EnemyLowestHealth` 是全新敌方目标面,阶段一不实现,先只做**自动触发**(不引入手动施放 UI),避免交互成本。
- **独占卡池过滤的回归**:过滤只改调用方构建的池,不改 `Roll` 内部;同种子确定性测试须保留,并新增"非选中指挥官的专属卡不进池"断言。
- **美术**:128 张新卡图标按"7 主题基座 × 21 机制徽章"组合生成(见《美术资源AI提示词》),先占位。
- **旧测试回归**:现有 33 条 §5.1 / 分析器测试全不受影响(新枚举为追加、新流派为注册表追加、上下文新增字段为 null 时加成恒 1)。

## 11. 性能与执行优化(150 卡复审)

### 11.1 性能层面

1. **商店 Roll 热路径(阶段二同步做)**:
   - 现状 `WeightFor(def, context)` 每个候选、每轮 Roll 计算**两次**(求和 + 选中),内部对 `def.Tags` 线性扫描;`CountOwnedTag` 又对 `OwnedTraitTags` 线性扫。150 卡池下 `OwnedTraitTags` 可达数十个,最坏是 **候选 × 标签 × 已拥标签** 三层扫描。
   - 三项 O(1) 化:
     - **同标签计数表**:Roll 内构建一次 `Dictionary<string,int>`(由 `OwnedTraitTags` 统计),`CountOwnedTag` 变查表。
     - **权重缓存**:一次 Roll 内预计算所有候选权重到并行 `float[]`(权重只依赖 def+context,不随移除变化),求和与选中都读缓存。
     - **标签集哈希**:`TraitCardDefinition` 惰性 `HashSet<string>`,`HasTag` 降 O(1)。
   - 达标门槛:150 卡(过滤后 50)Roll 总耗时 < 1ms(缓存后预计 < 0.1ms),不构成 UI 卡顿。
2. **池过滤的执行利好**:专属卡过滤发生在调用方构建候选池时。每局实际池子 = 150 − 100(5 位未选中指挥官的专属卡)= **50**,比不过滤小 1/3,Roll 循环更短。
3. **分析器短路(Affinity 脏标记)**:`RollOffers` 每次都 `RecomputeOwnedTags` + `Analyze`。优化:`SettlementShopSession` 在 `Buy / Sell / Equip / Unequip` 置 `_affinityDirty`;`RollOffers` 仅在 dirty 时重算,刷新(未改卡)直接复用上次 `Affinity`。注册表 8→20 后 `SelectSummary` 仍是微秒级,此短路主要省重复分配。
4. **战斗结算原则(阶段二核心)**:
   - **编译一次**:`TraitEffectService.BuildRuntime` 开战编译卡牌→编队效果集,不要在每帧/每命中重查 `TraitCatalog`。
   - **事件驱动,不轮询**:`OnHit / OnEnemyDeath / OnReceiveHit / OnBattleStart` 挂战斗事件总线;Update 主循环零新增逻辑。
   - **DoT 用 ticker**:`ApplyBurn` 走伤害 tick 计时器(每秒结算),不逐帧累加。
   - **按命中修正,不逐帧修正**:`ModifyCriticalChance / ModifyLifeSteal / ExecuteBonus / ReduceEnemyDefense` 是伤害管线一次性修正系数,命中时乘入。
   - **被动式数值在 spawn 时算一次**:`ModifyAttackRange / ModifyCriticalChance` 等像 `GetMaxHealthBonus` 在 `UnitSpawner.SpawnUnit` 算一次写进 `UnitRuntimeData`。
   - **同效果叠加顺序确定性**:编队多张卡可能含同效果种类(如两张 +攻),运行时应按**装备槽位升序**确定性合并,写死为结算约定,避免随机叠加。
   - **避免热路径分配**:结算复用对象池 / 局部 List,不给 GC 压力。

### 11.2 执行层面

1. **数据校验测试(128 张卡的守卫)**:期 1 每落一张卡,配套 EditMode"数据完整性"测试自动守护:
   - 150 张卡 `Id` / `DisplayName` 无重复。
   - 独占标签只出现在所属指挥官专属卡;每位指挥官 `ExclusiveTraitIds` 恰好 20 张且全部含独占标签。
   - 流派公式引用的标签都在词汇表内;每张卡 ≥1 效果 ≥1 标签;买价 > 卖价 > 0。
   - 数据量大时这是最省人的防线——谁提交错数据,测试立刻红。
2. **期 1 按指挥官拆分 PR**:128 张卡不一次提交。拆 **7 个 PR**:通用 8 张 + 每指挥官(20 张 + 2 条独占流派 + 对应数据测试)。每 PR 独立可测、可回滚,review 面小。
3. **机制解析器表**:新战斗机制用 `(EffectKind → Resolver)` 表注册,每加一个机制 = 1 条表项 + 1 个独立测试;`IsEffectSupported` 白名单兜底,未实现机制缺省禁用、不炸运行时。
4. **美术批次生成**:卡牌 128 张新增图标不逐张生成,改 **7 主题基座 × 21 机制徽章**组合,约 28 张提示词覆盖全部卡图标;打成一整张图集,UI 层叠加组合,运行时零额外纹理(策略与提示词见《美术资源AI提示词》)。
5. **性能回归基准**:加一条 EditMode 基准测试,断言 `Roll(150 卡池)` 耗时低于阈值(如 2ms),防未来加卡/改权重把商店拖慢。
6. **分期落地(每期独立 PR + 测试)**:
   - **期 1 · 数据层**:新枚举值(只加不改)、128 张新卡、12 条流派公式、6 指挥官字段填充 + 数据校验测试。纯数据,零运行时风险。
   - **期 2 · 商店层**:专属卡池过滤 + `CommanderAffinityMultiplier` + 标签计数/权重缓存 + Affinity 脏标记 + 商店/分析器测试。
   - **期 3 · 战斗结算逐效果放行**:暴击 → 减速 → 吸血 → 射程 → 护盾 → 灼烧 → 经济。每个效果独立 PR,先过 `IsEffectSupported` 白名单再接入结算。
7. **测试配套**:每个新效果 ≥1 条 EditMode 数值/边界测试;商店确定性测试保留;新增"非选中指挥官专属卡不进池"断言。

## 13. 待决问题

1. **新效果的分期范围**:阶段一是否只做"商店数据 + 独占流派判定"(效果留待阶段二),还是立即实现 `ModifyCriticalChance / SlowEnemy / ModifyLifeSteal` 三个最简结算?建议先数据后结算。
2. **专属卡是否占用普通卡槽**:目前 4 装备槽,而每指挥官专属卡有 20 张 → 构筑选择面大但装得少(最多 4 专属)。若要更宽松,可给专属卡"免费槽"、提高构筑向指挥官(达里奥)槽位(6 槽),或按装备卡数解锁槽位。
3. **旧共享流派去留**:本方案建议保留(通用泛流派),但若追求极致的"每指挥官流派独立",也可将旧 8 条共享流派从注册表移除、只留通用卡(通用卡仍带旧标签,但不构成可判定的流派)。倾向保留,理由:通用卡需要泛流派支撑商店引导。
4. **达里奥经济数值**:胜利金币 / 击杀金币 / 每 10 金币 +1% 攻,需实测调参,是唯一会改动金币结算流的机制。
5. **Legendary 卡**:本方案未含;若引入,可作为"某指挥官专属流派成型后解锁的传奇强化"(如伊莲娜成型后解锁「蛮王再临」),留作后续。
