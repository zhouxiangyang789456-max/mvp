# 指挥官设计文档

## 目标

把当前"随意"的 2 个指挥官(伊莲娜 / 卡西安)优化为 **6 个可玩指挥官**,每个都有:

- **独特的被动能力**(签名被动):全部用阶段一已支持的卡牌效果体系落地,立即可以进战斗;6 人的 (效果,触发) 组合两两不同,无重复。
- **独特的特色机制**(后期):六人六关键词——**阈值 / 防御 / 机动 / 运营 / 射程 / 位置**,互不重叠;后期据此落地新结算。
- **明确的流派方向(2~3 个)**:每位指挥官 = 1 个主流派 + 1~2 个副流派,由一个**核心标签**串联;商店 §5.1 动态判定玩家实际走向——选人不是锁死一条流派,而是打开 2~3 扇门。
- **远程火力 = 攻击范围增加**:奥莉薇是唯一"射程"指挥官(远程单位攻击范围增加),独立于其余五位,不与其他机制混用。

本文档不实现代码,只给出设计 + 实现建议(字段扩展、接入点、涉及文件)。

## 设计原则

1. **指挥官 = 流派入口,不是独立小游戏。** 指挥官的身份通过两条线落地:
   - 战斗线:签名被动(全局数值)。
   - 构筑线:核心标签 + 2~3 个流派方向 → 商店出卡偏向(复用 §5.1 `ArchetypeSynergyMultiplier` 动态判定)。
2. **阶段一全部可落地。** 6 个签名被动只用 5 种已支持效果 + 3 种已支持触发 + `AllGroupMembers` 作用域,数值与现有卡牌同量级,不需要新运行时;(效果,触发) 组合两两不同,无重复。
3. **特色机制是"差异化",不是强度。** 后期机制不与被动叠加成超模,而是提供玩法上的区别(护盾、冲锋、双流派、射程、范围轰炸、背袭)。
4. **同类效果用触发条件区分**,避免重复感;6 人 (效果,触发) 组合两两不同——攻击 3(伊莲娜低血 / 达里奥高血 / 奥莉薇常驻)、减伤 1(卡西安高血)、移速 2(薇拉常驻 / 伊凡高血)。
5. **指挥官不锁单流派,开 2~3 扇门。** 每位指挥官给 1 个主流派 + 1~2 个副流派,由核心标签串联;流派池可被多人共享(如薇拉 / 伊凡同走高血机动流),共享者靠**特色机制 + 起始部队**区分,不靠独占流派。
6. **难度梯度拉开**,覆盖新手(简单站桩)到高手(阈值管理 / 经济运营)。

## 能力模型

### 现状

`CommanderDefinition`(`Assets/Scripts/Shared/CommanderDefinition.cs`)只有:

```csharp
public string Id;                    // commander_elena
public string DisplayName;           // 伊莲娜
public int MaxHealth;
public int CurrentHealth;
public string PortraitAssetId;
public string MapPortraitAssetId;
public List<string> Traits;          // 纯文本特征词(无机制)
public List<StartingUnitEntry> StartingUnits;  // 开局部队
```

没有技能、没有流派绑定。`Traits` 目前只是展示词。

### 需要的字段扩展(建议)

```csharp
using Mvp.Progression;   // TraitEffect 位于该命名空间

public sealed class CommanderDefinition
{
    // ...现有字段...

    public string Title;                    // 称号,如"绯红猎犬"(展示用)
    public TraitEffect Passive;             // 签名被动(阶段一可落地)
    public List<string> CoreTags;           // 核心标签种子,如 ["low_health"](见"商店集成")
    public List<string> AffinityArchetypeIds; // 2~3 个流派方向,如 ["archetype_low_health_burst", "archetype_low_health_counter"]
    public int StartingGold;                // 开局金币(可选;达里奥专用)
}
```

### 签名被动 → 现有卡牌效果体系

被动就是一条 `TraitEffect`,字段与 `Assets/Scripts/Progression/TraitEffectModels.cs` 完全一致。阶段一白名单(`IsEffectSupported`):

- 效果: `ModifyMaxHealth` / `ModifyAttackPower` / `ModifyAttackCooldown` / `ModifyMoveSpeed` / `ReduceIncomingDamage`
- 触发: `Always` / `WhileGroupHealthBelowPercent` / `WhileGroupHealthAbovePercent`
- 作用域: `AllGroupMembers`

> 实现提示:战斗侧把指挥官被动当作一张"天生常驻卡"合并进 `TraitRuntimeResolver` 产出的编队效果,即可复用现有结算管线,零新机制。

### 特色机制 → 后期效果体系

特色机制映射到已定义但阶段一未生效的 `TraitEffectKind` / `TraitTriggerKind` / `TraitTargetScope`(见 `TraitEffectModels.cs` 注释)。落地顺序依赖后续战斗数值结算。

## 流派池(卡牌构筑体系)

卡牌标签是流派的"字",流派公式是"词"。流派池从 5 条扩充到 **8 条有效 + 1 条预留**,覆盖 血量状态(低血 / 高血 / 厚血) × 战斗节奏(爆发 / 攻速 / 消耗) × 空间(机动 / 阵地) × 指挥:

| 流派 | 公式 | 定位 | 关键卡 |
|------|------|------|--------|
| 低血爆发流 | low_health×2, attack×1, cooldown×1 | 残血换爆发,玻璃大炮 | 勇敢 / 回光反照 / 迅捷 / 疾攻 |
| 低血反扑流 | low_health×2, defense×1, sustain×1 | 残血更硬,挨打反打 | 拒止 / 复苏 / 回光反照 |
| 阵地防守流 | defense×2, formation×1, idle×1 | 站桩减伤,阵地战 | 守备 / 坚守 / 沉着 / 纪律 |
| 高血机动流 | mobility×2, high_health×1, attack×1 | 优势拉扯,打带跑 | 鼓舞 / 迂回 / 昂扬 / 充沛 |
| 厚血消耗流 | max_health×2, defense×1, sustain×1 | 血牛拖消耗,以拖待变 | 厚重 / 坚韧 / 充沛 / 复苏 |
| 高血强攻流 | high_health×2, attack×1, cooldown×1 | 满血站撸,持续输出 | 昂扬 / 充沛 / 迅捷 / 疾攻 |
| 均衡指挥流 | commander×2, balanced×1, support×1 | 全面增幅,指挥层 | 号令 / 军心 / 均衡 / 支援 |
| 机动游击流 | mobility×2, cooldown×1, attack×1 | 高速袭扰,闪电出手 | 鼓舞 / 迂回 / 迅捷 / 疾攻 |
| 远程火力流* | range×2, attack×1, cooldown×1 | 射程 + 范围压制(预留) | 待 `range` 标签落地 |

> 新增的 **低血反扑流 / 高血强攻流 / 机动游击流** 全部由现有卡牌标签组合而成;扩池只改 `TraitBuildAnalyzer.ArchetypeRegistry` 注册表,零代码逻辑改动。

## 指挥官详设

### 1. 伊莲娜 · 绯红猎犬 —— 低血爆发流

- **定位**:高风险高回报,玻璃大炮。以残血换爆发,擅长残局收割。
- **背景**:佣兵出身的猎犬,信奉"活着赢不了,死前多咬一口"。
- **签名被动 · 背水一战**(可落地):
  ```csharp
  Passive = new TraitEffect {
      Kind        = TraitEffectKind.ModifyAttackPower,
      Trigger     = TraitTriggerKind.WhileGroupHealthBelowPercent,
      TriggerValue = 0.35f,          // 编队生命低于 35%
      Scope       = TraitTargetScope.AllGroupMembers,
      Value       = 0.25f            // 全队攻击力 +25%
  };
  ```
- **特色机制 · 以血铸刃**(后期):编队生命每低于阈值 10%,攻击冷却再 -3%(多段叠加)。映射:多段 `WhileGroupHealthBelowPercent` + `ModifyAttackCooldown`,或新增"按损失生命插值"结算。
- **起始部队**:步兵×2 + 坦克×1(沿用)。
- **生命**:100(全场最低档)。
- **特征词**:勇敢 / 激进 / 爆发 / 嗜血。
- **流派方向**(核心标签 `low_health`,起始种子让各方向早期都有分):
  - **主流派 · 低血爆发流**:与签名被动(低血触发)完全一致,残血换爆发,玻璃大炮。
  - **副流派 · 低血反扑流**:残血加防御/复苏,走"越残越硬、挨打反打";被动攻击加成在残血期仍生效。
- **上手难度**:★★★★☆ —— 需要压血线,防被秒。
- **玩法思路**:控编队血量在 35% 上下徘徊,让背水一战常驻;商店优先买 low_health / attack / cooldown 标签,维持低血爆发成型。

### 2. 卡西安 · 铁壁总督 —— 阵地防守流

- **定位**:防守反击,稳扎稳打。满血越硬,适合正面推。
- **背景**:前军校教官,主张"阵线不破,后方才能安心"。
- **签名被动 · 铁壁防线**(可落地):
  ```csharp
  Passive = new TraitEffect {
      Kind        = TraitEffectKind.ReduceIncomingDamage,
      Trigger     = TraitTriggerKind.WhileGroupHealthAbovePercent,
      TriggerValue = 0.70f,          // 编队生命高于 70%
      Scope       = TraitTargetScope.AllGroupMembers,
      Value       = 0.20f            // 全队所受伤害 -20%
  };
  ```
- **特色机制 · 坚不可摧**(后期):编队生命首次跌破 50% 时获得一层护盾。映射:`OnFirstHitTaken` / `OnBattleStart` + `GrantOpeningShield` + `AllGroupMembers`。
- **起始部队**:步兵×3 + 坦克×1(沿用)。
- **生命**:120。
- **特征词**:沉着 / 守备 / 纪律 / 坚守。
- **流派方向**(核心标签 `defense`):
  - **主流派 · 阵地防守流**:与签名被动(高血减伤)一致,站桩减伤。
  - **副流派 · 厚血消耗流**:血牛拖消耗,高血减伤被动在满血期持续生效。
  - **副流派 · 高血强攻流**:满血站撸,被动减伤保护下输出。
- **上手难度**:★★☆☆☆ —— 站住阵线即可。
- **玩法思路**:保持高血维持减伤;商店买 defense / formation / idle 标签,配合阵地防守成型。

### 3. 薇拉 · 风隼 —— 高血机动流

- **定位**:机动游走、包抄侧翼。高速高血,打带跑。
- **背景**:侦察队出身的斥候,信奉"先到一步,胜负已分"。
- **签名被动 · 猎风疾行**(可落地):
  ```csharp
  Passive = new TraitEffect {
      Kind   = TraitEffectKind.ModifyMoveSpeed,
      Trigger = TraitTriggerKind.Always,
      Scope  = TraitTargetScope.AllGroupMembers,
      Value  = 0.15f                 // 全队移动速度 +15%
  };
  ```
- **特色机制 · 先行一步**(后期):进入战斗时全队获得一层"冲锋",首次攻击伤害 +30%。映射:`OnFirstAttack` + `ModifyAttackPower`(一次性增益)。
- **起始部队**:坦克×2(高血高速,初始肉搏强但单位少)。
- **生命**:90。
- **特征词**:迅捷 / 机动 / 迂回 / 猎手。
- **流派方向**(核心标签 `mobility`):
  - **主流派 · 高血机动流**:高速优势拉扯,与签名被动(常驻移速)一致。
  - **副流派 · 机动游击流**:高速袭扰,靠攻速在机动中更快出手。
- **上手难度**:★★★☆☆ —— 用机动拉扯,别被围。
- **玩法思路**:靠机动抢占先手;商店买 mobility / high_health / attack 标签,维持高血机动成型。

### 4. 达里奥 · 佣兵团长 —— 灵活 / 经济 / 商店羁绊

- **定位**:经济运营型,靠商店滚雪球。开局弱,后期爆发。
- **背景**:雇佣兵团长,给钱就干活,"合同永远留一手"。
- **签名被动 · 速成训练**(可落地):
  ```csharp
  Passive = new TraitEffect {
      Kind        = TraitEffectKind.ModifyAttackPower,
      Trigger     = TraitTriggerKind.WhileGroupHealthAbovePercent,
      TriggerValue = 0.70f,          // 编队生命高于 70%
      Scope       = TraitTargetScope.AllGroupMembers,
      Value       = 0.12f            // 全队攻击力 +12%(优势时进攻)
  };
  ```
- **特色机制 · 双面合同**(商店 / 后期可立即落地):商店补强同时覆盖**主流派 + 副流派**(副 ×0.5)。映射:复用 `BuildAffinitySummary.SecondaryArchetypeId`,在 §5.1 补强上叠加一条"副流派弱补强"。六人都不锁单流派,但达里奥是唯一可挂 3 条、跨越不同家族(强攻 / 机动 / 指挥)的,配合双面合同把两条线同时铺开。
- **起始部队**:步兵×4(便宜人海,靠经济补强)。
- **生命**:95。
- **特征词**:逐利 / 变通 / 雇佣 / 市侩。
- **流派方向**(核心标签 `high_health`;达里奥唯一可挂 3 条、跨越不同家族):
  - **主流派 · 高血强攻流**:满血站撸,与签名被动(高血攻)一致。
  - **副流派 · 高血机动流**:优势机动,配合经济转战力拉扯。
  - **副流派 · 均衡指挥流**:"全能"方向,契合其灵活/运营身份;配合特色机制"双面合同"(主+副都强化)把两条线同时铺开。
- **上手难度**:★★★★★ —— 前期脆、单位弱,必须精打细算金币与构筑。
- **玩法思路**:前期苟住,靠商店多刷、双流派补强把构筑铺成两条线;经济转战力,后期成型碾压。

### 5. 奥莉薇 · 鹰眼 —— 远程火力流

> 后 2 位(奥莉薇 / 伊凡)强调"指挥官指挥下方军事单位行动"这一维度:不止是常驻被动,而是通过**射程 / 位置结算**影响战斗走势。奥莉薇打面(射程 + 范围轰炸),伊凡打点(背袭)。签名被动阶段一即可落地;特色机制(超视距打击 / 背袭)属于新的战斗结算方向,放后期,且**不依赖将来的兵种克制系统**(克制是单位层,这是指挥层,两者正交)。

- **定位**:远程火力压制,以远程打击削弱敌方,打面不打点。克制密集站桩、克制阵地防守,怕高机动近身。
- **背景**:神射手出身的远程指挥官,信奉"让对方还没摸到你,就已经输了"。
- **签名被动 · 强袭火力**(可落地):
  ```csharp
  Passive = new TraitEffect {
      Kind   = TraitEffectKind.ModifyAttackPower,
      Trigger = TraitTriggerKind.Always,
      Scope  = TraitTargetScope.AllGroupMembers,
      Value  = 0.12f            // 全队攻击力 +12%(远程火力基础)
  };
  ```
- **特色机制 · 超视距打击**(后期,签名,双机制合一):
  1. **射程增加**——远程单位攻击范围 +N(新增 `ModifyAttackRange` 效果种类 + 放行 `RangedMembers` 作用域)。这正是"远程火力 = 远程单位攻击范围增加"的正解,奥莉薇是唯一"射程"指挥官。
  2. **范围轰炸**(原雷娜·炮火覆盖)——每 N 秒对敌方编队最密集区域自动执行一次范围炮击,区域内单位受到伤害;或开局获得一次"预备轰炸"。映射:新增"范围伤害"结算 + "按区域"目标选取(自动判定,不需要手动施放 UI)。

  射程与范围天然联动:射程越远,可覆盖区域越大,两条机制互为放大器。
- **起始部队**:步兵×2 + 坦克×1(前排保护)。
- **生命**:95(远程脆皮)。
- **特征词**:远程 / 精准 / 压制 / 鹰眼。
- **流派方向**(核心标签 `attack`;射程标签落地前主方向为预留):
  - **主流派 · 远程火力流**(预留):range×2, attack×1, cooldown×1。当前卡牌池无 `range` 标签、无 `ModifyAttackRange` 效果,该亲和暂不生效;待射程机制落地、`range` 标签上线后自然接管。阶段一可退化为"低血爆发流"的 attack/cooldown 标签做临时商店引导(可选)。
  - **副流派 · 低血爆发流**:远程残血爆发(回光反照等),与常驻攻被动兼容。
  - **副流派 · 阵地防守流**:远程单位靠前排保护,防守标签强化"够不着你就赢"。
- **上手难度**:★★★☆☆ —— 站位靠后,防高机动近身。
- **玩法思路**:保持阵线让远程单位安心输出;特色机制落地前,先靠常驻攻击强化 + 攻击/冷却标签推进商店构筑;射程机制上线后以"够不着你就赢"为核心打法,超视距打击远程削弱敌方阵型。

### 6. 伊凡 · 夜鸦 —— 机动突袭流

- **定位**:特种游击,背袭先手,打时间差。克制脆皮 / 孤军 / 炮台,怕阵地工事。
- **背景**:夜战出身的侦察兵,信奉"先动手的人赢一半"。
- **签名被动 · 追歼令**(可落地):
  ```csharp
  Passive = new TraitEffect {
      Kind         = TraitEffectKind.ModifyMoveSpeed,
      Trigger      = TraitTriggerKind.WhileGroupHealthAbovePercent,
      TriggerValue = 0.70f,          // 编队生命高于 70%
      Scope        = TraitTargetScope.AllGroupMembers,
      Value        = 0.20f           // 全队移动速度 +20%(优势追歼 / 拉扯找背)
  };
  ```
- **特色机制 · 背袭**(后期):从敌方单位侧翼 / 背后发起攻击时,首次攻击伤害 +50%(位置判定);或开局全员获得"先手"(进入战斗后首次攻击 +30%)。映射:新增"攻击方向 / 位置"结算 + `OnFirstAttack`。自动判定方向,不需要玩家手动操作。
- **起始部队**:步兵×2 + 坦克×1。
- **生命**:95。
- **特征词**:游击 / 突袭 / 机动 / 先手。
- **流派方向**(核心标签 `high_health` / `mobility`):
  - **主流派 · 高血机动流**:与签名被动(高血移速)一致,高速拉扯找背身。
  - **副流派 · 机动游击流**:高速袭扰,更快出手打背袭。
  - **副流派 · 厚血消耗流**:高血硬突进,背袭后能扛。
- **上手难度**:★★★★☆ —— 要利用移速拉扯找背袭角度,操作要求高。
- **玩法思路**:靠高血移速拉扯,背袭秒杀脆皮;配合高血机动流(薇拉)双移速叠加,机动封顶后绕后压制。

## 商店与流派集成(§5.1 接入)

### 现状

`SettlementShopSession.RollOffers()` 每次刷新:

```csharp
_rollContext.Affinity = TraitBuildAnalyzer.Analyze(_rollContext.OwnedTraitTags);
```

`TraitShopDirector.ArchetypeSynergyMultiplier` 只在 `Maturity != Unformed`(主流派得分 ≥4)时按主流派公式标签给乘性补强(×1 ~ ×1.75)。**未成型时商店不偏置。**

### 推荐方案(方案 B):指挥官流派方向补强

指挥官不锁单流派,而是定义 **2~3 个亲和流派 + 核心标签种子**。商店在未成型阶段就提供方向,但不违反 §5.1 的成型门槛:

- **核心标签种子**:`CommanderDefinition.CoreTags`(如伊莲娜 = `[low_health]`)注入 `_rollContext.OwnedTraitTags` 后再 `Analyze`。只给核心标签、不给完整公式 → 2~3 条路线早期都有"正在成型"的分,但**开局不锁死任何一条**(§5.1 门槛仍要求主流派得分 ≥4)。玩家买哪条,§5.1 动态判定就把哪条推成主流派。
- **方向补强层**:`TraitShopDirector` 增加 `CommanderAffinityMultiplier(def, context)`:
  - 恒生效(无论是否成型)。
  - 候选卡携带任一亲和流派公式标签时,给一个较小的乘性加成(建议 `×1.25`,阈值常量可调)。
  - 未成型时用它引导;已成型时叠加 §5.1 主流派补强(若玩家遵从指挥官方向,二者自然叠加;若偏离,则过渡到玩家自己的构筑)。
- **选人定向(可选加强)**:选人时可挑一个"本局主方向",对该方向补强更高(`×1.5`),其余副方向 `×1.25`。达里奥天然契合——他的"双面合同"就是把主+副同时强化。
- 实现要点:`context` 增加 `SelectedCommanderId` / `CoreTags` / `AffinityArchetypeIds`;`Director` 只读 DTO 风格字段,不依赖分析器(与 §5.1 约束一致)。

**效果**:开局商店就偏向指挥官的核心标签 → 引导玩家进入其 2~3 条流派路线 → 玩家买哪条,§5.1 成型后就接管哪条 → 指挥官选择真正成为流派入口。

### 方案 A 的历史备注(已并入方案 B)

原"起始流派标签种子"方案注入完整流派公式标签,会让流派开局就成型、构筑自由度下降。方案 B 只注入**核心标签**,保留同样的引导能力但避免开局锁死——建议按方案 B 实现。

### 达里奥的双面合同(方案 B 的自然扩展)

`ArchetypeSynergyMultiplier` 基础上,对副流派(`BuildAffinitySummary.SecondaryArchetypeId`)给 `×0.5` 的补强。仅在达里奥被选中时启用。

## 平衡数值框架

- **被动强度 ≈ 1 张常驻卡**:阶段一卡牌单效果约 0.15–0.25,指挥官被动取 0.10–0.25,且全部 `AllGroupMembers`。条件触发(低血/高血)数值略高(0.20–0.25),常驻数值略低(0.10–0.15)。

# 扩展章节:特殊机制库与传奇指挥官

> 前文 6 位是"常规指挥官"(签名被动全部阶段一可落地)。本节补充**特殊机制库**与**传奇指挥官**——后者由多个机制组合而成,追求自走棋式 1+1>2 的涌现强度,部分是后续阶段目标。

## 特殊机制库(按系统分类)

### A. 编队 / 部队类

| 机制 | 效果 | 1+1>2 组合价值 | 落地接缝 |
|---|---|---|---|
| **扩编** | 编队单位上限 +N(部署格 + 队形槽扩容) | 能带更多单位 → 更容易触发同袍羁绊阈值 | `UnitSpawner` 部署区 + `DeploymentAreaPlanner` 槽位 |
| **同袍羁绊** | 编队同兵种 ≥3 时全体获得组合加成(3坦克=装甲联合+护甲;3步兵=训练有素+攻速) | 数量本身变成强度,激励堆单一兵种 | 新增"按编队构成"的结算 |
| **兵种协同** | 步+坦同队时,步兵获"掩护"-伤、坦克获"支援"+攻速 | 鼓励混合编队,前后排配合 | 同上,按兵种混合判定 |
| **军械强化** | 指定兵种全局强化(如坦克+生命) | 与扩编/同袍叠加,聚焦单兵种流派 | `UnitCatalog` 补丁或指挥官被动 |

### B. 卡牌 / 构筑类(接 §5.1 商店)

| 机制 | 效果 | 1+1>2 组合价值 | 落地接缝 |
|---|---|---|---|
| **博学者** | 装备卡牌槽 4→6 | 流派更容易成型 → 主流派分更高 → 商店补强系数更大 | `CommanderLoadoutSnapshot` 槽位数组按指挥官扩容 |
| **补卡** | 每轮商店候选卡 +1 | 更容易凑齐流派标签 | `SettlementShopSession` roll 数量 |
| **定向补给** | 每轮必出一张与主流派标签匹配的卡 | 稳定推进成型,减少运气 | 商店选卡过滤 |
| **卡牌羁绊(叠卡)** | 编队同定义卡 ≥2 时效果提升 | 2 张同卡 > 2×1 张的纯数值,触发额外加成 | `TraitRuntimeResolver` 叠加逻辑 |
| **重铸** | 每轮把一张卡重掷成同稀有度 | 转化废卡,提高构筑弹性 | 商店卖出/重掷流程 |

### C. 经济类

| 机制 | 效果 | 1+1>2 组合价值 | 落地接缝 |
|---|---|---|---|
| **利息** | 每回合按金币存量 X% 计息 | 鼓励囤金 → 一次性爆买 → 快速成型 | 金币系统 |
| **雇佣兵** | 战斗前可用金币临时租借额外单位 | 金币→单位→触发同袍羁绊,把经济转即时战力 | 战前招募 UI + 编队扩容 |
| **战利品** | 每场胜利额外金币 | 滚雪球,配合利息/雇佣 | 战果结算 |

### D. 战斗 / 生存类

| 机制 | 效果 | 1+1>2 组合价值 | 落地接缝 |
|---|---|---|---|
| **不灭 / 重整** | 编队首次被击溃后残部复活一次 | 翻盘;配合厚血消耗流更强 | `CommanderGroupState.Defeated` / `AfterRegroup` |
| **副官 / 召唤** | 战斗中额外召唤一个召唤单位 | 多一个单位 → 同袍阈值 + 输出 | 召唤型机制,暂不做(召唤师仅为构思方向,本期不实现) |
| **阵地工事** | 部署范围内地形给增益 | 阵地防守流自带主场优势 | `WhileFormationIntact` |
| **士气** | 存活单位越多,全体越强 | 滚雪球:越强越不易死,越不易死越强 | `ModifyCommanderMorale` |

## 1+1>2 设计原则

- **引擎是"机制互喂",不是"高数值"**:扩编喂同袍,利息喂雇佣,博学者喂双流派。单个机制不超模,组合起来才有上限。
- **代价与风险要配套**:扩编的单位会拉低单个单位投入;钢铁洪流怕高伤爆发(被伊莲娜低血流克制);经济流前期弱。
- **落地分级**:同袍羁绊 / 兵种协同 / 士气属"按编队构成的结算"(新结算系统,后期);扩编 / 博学者 / 补卡 / 利息 / 重铸属"改动现有数据结构/流程"(中期可做)。

## 传奇指挥官候选

> 传奇指挥官 = 多个特殊机制的合成体,强度上限更高、上手更复杂。可作为第 7~10 位扩展,或作为"高难度解锁"奖励。

### 传奇·钢铁洪流(坦克海)

- **定位**:正面硬推,用数量碾压。
- **机制组合**:扩编(+单位上限) + 坦克同袍羁绊(≥3 坦克→装甲联合:全队减伤) + 坦克军械强化(坦克最大生命+15%)。
- **签名被动(可落地)**:军械强化——坦克单位最大生命 +15%。注意当前阶段一作用域仅 `AllGroupMembers`,需要扩展 `TankOnly` / `FrontlineMembers` 作用域才能精确到兵种。
- **起始部队**:坦克×3。
- **生命**:120。
- **上手难度**:★★★☆☆。
- **玩法思路**:无脑堆坦克,数量叠出同袍羁绊,正面推进。

### 传奇·不死军团(献祭流)

- **定位**:死兵换增益,残局最强。
- **机制组合**:扩编 + 单位死亡给剩余成员增益 + 不灭(编队首次被击溃后残部复活一次)。
- **签名被动(可落地)**:每少一个存活单位,全体攻击 +8%(最多 +32%)。按存活数缩放,评估简单可立即做。
- **起始部队**:步兵×5(人海,扩编)。
- **生命**:110。
- **上手难度**:★★★★☆。
- **玩法思路**:用便宜步兵填编队,死得越多剩的越强,配合不灭在残局翻盘。

### 传奇·军师(构筑大师)

- **定位**:构筑天花板最高,卡牌流。
- **机制组合**:博学者(装备槽 6) + 定向补给 + 双流派补强(复用 §5.1 副流派)。
- **签名被动(可落地)**:每装备 1 张卡,全队攻速 +2%(按装备卡数缩放,评估简单可立即做)。
- **起始部队**:步兵×3 + 坦克×1。
- **生命**:100。
- **上手难度**:★★★★☆。
- **玩法思路**:6 槽双流派,三个机制互相喂:多槽→双流派成型→商店双补强→更多定向卡。

### 传奇·掘金者(经济流)

- **定位**:经济滚雪球,后期爆发。
- **机制组合**:利息(每回合按金币存量 X% 计息) + 雇佣兵(战斗前金币临时租借单位) + 战利品(胜利额外金币)。
- **签名被动(可落地)**:常驻移动速度 +10%(前期闪避/拉扯,弥补开局弱)。
