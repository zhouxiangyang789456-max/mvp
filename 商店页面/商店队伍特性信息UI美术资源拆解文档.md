# 商店队伍特性信息 UI 美术资源拆解文档

## 1. 整体美术方向

用途场景：商店弹窗弹出时，下方同步显示当前出征队伍中每名指挥官的头像、特性、兵种/定位等信息。

目标风格：明亮卡通低模 3D、玩具模型质感、手绘木质小面板、圆形金属头像框、清晰小图标、暖色幻想策略游戏 UI。

统一风格提示词：

```text
低多边形风格化 3D 游戏 UI 资源，明亮卡通配色，玩具模型质感，手绘木质纹理，柔和左上方光照，清晰倒角边缘，暖色幻想策略游戏界面，小尺寸信息面板仍然清楚可读，轻微笔触颗粒，高质量手游 UI，透明背景
```

统一负面提示词：

```text
写实照片质感，暗黑恐怖风格，科幻金属界面，复杂花纹，脏乱磨损，强透视，模糊边缘，文字乱码，英文文字，中文文字，水印，复杂背景，过度发光
```

建议统一画布：

- 基准 UI 分辨率：`1600 x 900`
- 单个资源格式：`PNG`
- UI 零件：透明背景
- 如果生成整组预览：建议透明背景，尺寸按 `300 x 92`
- 文字：全部不要让 AI 生成，后续在 Unity 中用 TextMeshPro 叠加
- 光源方向：左上方柔和暖光
- 图标线条：深棕色，保证缩小后可读

## 3. 推荐布局尺寸

### 3.1 单个指挥官特性组件整体

用途：下方横向排列的单名指挥官信息块。

建议尺寸：`300 x 92`

背景要求：透明背景。

结构建议：

- 左侧圆形头像徽章：约 `78 x 78`
- 右侧 2x2 特性小格：约 `170 x 72`
- 整体有轻微投影，但不要带大面积背景
- 文本不烘焙进图，图标和文字分层更灵活

提示词：

```text
单个指挥官队伍特性信息组件，横向小型 UI 面板，左侧为圆形金色头像徽章，右侧为四个小木牌信息格组成的 2x2 区域，暖棕色手绘木纹，清晰 3D 倒角，玩具模型质感，柔和左上方光照，适合放在商店弹窗下方，透明背景，不要文字，不要具体人物，不要复杂背景
```

## 5. 不建议由 AI 生成的内容

以下内容建议在 Unity 中使用 TextMeshPro 或程序生成：

- 左侧标题：`队伍`
- 特性文字：如 `勇敢`、`谨慎`、`披甲`、`坚韧`
- 兵种/定位文字：如 `骑兵`、`步兵`、`弓兵`
- 指挥官名字、等级、星级、数值
- 所有动态状态文字和数量

原因：AI 生成中文容易乱码，且这些内容会随指挥官、特性、语言版本和状态变化。

## 6. Unity 组合建议

- 推荐分层：头像框、头像、右侧四宫格底板、图标、文字、选中高亮、禁用遮罩
- 单个组件推荐 RectTransform：`300 x 92`
- 横向间距建议：`36-48 px`
- 队伍标题与第一张组件间距建议：`70-90 px`
- 四个组件总宽约：`4 x 300 + 3 x 36 = 1308 px`
- 如果屏幕较窄，组件可缩放到 `0.8`，但图标不要低于 `24 x 24`
- 特性格文字建议字号：`20-24`
- 标题“队伍”建议字号：`30-36`
