# 商店 UI 美术资源拆解文档

## 1. 整体美术方向

目标风格：明亮卡通低模 3D、玩具模型质感、手绘木质与羊皮纸材质、柔和环境光、边缘清晰、轻微倒角、轻微颗粒笔触纹理。

统一风格提示词：

```text
低多边形风格化 3D 游戏 UI 资源，明亮卡通配色，玩具模型质感，手绘纹理，柔和光照，清晰倒角边缘，暖色木质幻想界面，形状干净可读，轻微笔触颗粒，高质量手游 UI，透明背景
```

中文风格提示词：

```text
低多边形风格化 3D 游戏 UI 资源，明亮卡通配色，玩具模型质感，手绘纹理，柔和光照，清晰倒角边缘，暖色木质幻想界面，形状干净可读，轻微笔触颗粒，高质量手游 UI，透明背景
```

建议统一画布：

- 基准 UI 分辨率：`1600 x 900`
- 单个资源建议导出：`PNG`
- 普通 UI 零件：透明背景
- 可平铺材质：透明背景或纯中灰背景各导出一版
- 阴影：建议资源自带轻微接触阴影，但不要带大面积投影
- 光源方向：左上方柔和暖光
- 视角：正面 UI 视角，允许轻微 3D 厚度，但不要强透视

## 4. 字体与文字建议

外部 AI 不建议生成中文文字。所有中文、价格数字、数量 `x5`、`x7`、`x10` 建议在 Unity 内用 TextMeshPro 实现。

推荐文字风格：

- 标题：粗体、偏手写或楷体感，颜色 `#F4E2B8`
- 正文：深棕色 `#2F1B10`
- 价格数字：深棕色或黑棕色，带轻微描边
- 顶部金币数字：金黄色或浅黄色，带深色阴影

## 5. Unity 导入建议

- UI 主面板、按钮、木牌类资源建议开启 `Sprite Mode: Single`
- 可拉伸面板建议额外制作九宫格版本，并在 Sprite Editor 中设置 Border
- 所有透明 PNG 建议保留 8-16 px 安全留白，避免阴影被裁切
- 同类按钮保持统一光源、统一阴影方向
- 文字、价格、数量、技能描述全部用程序或 UI 文本叠加
